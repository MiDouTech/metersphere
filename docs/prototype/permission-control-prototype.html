新旧权限兼容策略
旧权限代码不删除。迁移期间使用适配层隔离，已迁移页面走资源目录，未迁移页面继续走旧权限。
场景 旧逻辑 新逻辑 处理策略
页面访问 route.meta.roles resourceCode + 页面可见 有 resourceCode 优先新逻辑，否则旧逻辑兜底
按钮隐藏 v-permission v-visible-permission 迁移页面添加注释标记，保留接口权限
按钮禁用 多数页面无统一能力 v-operable-permission 新逻辑必须同时校验旧 permissionId
接口安全 @RequiresPermissions 继续使用 不允许前端 UI 权限替代后端权限
流程流转 status_flow status_flow + role permission 新增授权表，后端执行时强校验
