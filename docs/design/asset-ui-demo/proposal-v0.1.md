# 业务资产与公共配置 UI 优化方案 v0.1
日期：2026-11-20；状态：草稿，待用户确认。原型示例不代表正式功能实现。
依据：用户本轮六项要求；已批准产品基线 MSP-业务资产重建与受控执行清理 v1.0（20261119）。

## 设计方向
推荐保留现有紫色与 Arco 组件体系，采用白色内容卡片、统一工具栏和紧凑表格。避免另起一套视觉语言。仅调整颜色和间距无法解决表单结构与版本信息层级问题，因此本方案同时重组交互。

## 表单与安全规则
账号密码类固定账号、密码字段，允许增加租户等自定义字段；其他类以自定义字段起步。字段名去首尾空格，非空且同一配置内不重复；值不能为空。至少保留一个有效字段，数量和长度上限在正式协议中统一约束。
所有敏感字段值均加密，列表、版本、日志和普通上下文不展示。编辑不回填明文；正式实现需明确保留旧值与替换值的操作，不能用空字符串隐式覆盖。切换类型时有未保存输入应提示丢弃确认。
旧 SECRET 单值不能推断为账号密码，兼容归入“其他”，不自动拆解。账号密码结构变更需同步执行器和 MCP 调用方，不能仅将新 UI 接到旧单值接口即视为交付。
新建一次保存生成一个版本，移除表单内外重复提交按钮。保存失败保留输入，成功及关闭清理敏感值；不持久化到浏览器缓存。

## 页面和异常行为
正式页面复用系统组件，统一按钮高度、间距、边框、表格行高。加载显示 loading；无数据给出新建/上传入口；查询无结果允许清空筛选；目录加载失败显示重试，不与空数据混淆。
无写权限隐藏维护操作，后端仍校验权限。网络和服务错误给安全提示及关联编号。
版本切换需填写原因并确认；当前版本不可重复切换。敏感历史只显示元信息。现有在执行任务保持固定版本。

## 原型范围与验收
index.html 是可离线打开的独立原型，不修改应用代码、不调用接口、不保存配置。
可切换三个页面、搜索名称、打开配置弹窗、切换敏感子类、添加删除字段、进行必填校验、查看版本与切换提示。
分类树、系统筛选、新建业务理解、上传导入和版本切换为视觉或提示占位，不代表已实现。
正式链路：页面 → 项目权限 → /business-assets 或 /shared-configurations → 参数业务校验 → 版本与加密持久化 → 执行器授权解析。该链路本轮不改动。
用户确认方向后，再编写正式实现计划、补充协议与迁移设计，进行开发、自测和独立审查。

## 工具栏布局补充（2026-11-23，用户明确要求）
三个页面统一采用左操作、右检索：新增为左侧首个主按钮，上传、批量导入和刷新等操作随后排列；名称搜索、系统、环境及状态筛选放在右侧。空间不足时检索区换行并靠右。弹窗底部保存、取消和表格行内操作不属于页面工具栏，保持原位置。
