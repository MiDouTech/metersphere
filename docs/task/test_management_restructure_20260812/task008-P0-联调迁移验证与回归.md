# task008 P0：联调、迁移验证与回归

## 测试范围

- 四种项目/系统归属组合的创建、编辑、查询和删除。
- 项目与系统 TAB 切换、目录计数、筛选和分页。
- 项目权限、工作空间权限及混合数据的越权测试。
- 评审、报告迁移及历史路由兼容。
- 项目列表、详情、进入项目及当前项目状态。
- 导入、导出、复制、批量操作、回收站和自动化执行。
- 数据升级脚本、重复执行及异常恢复。

## 必测场景

1. 项目和系统均为空的用例可正常使用。
2. 无项目用例不会出现在无工作空间权限用户的结果中。
3. 有项目无系统用例出现在项目目录和系统待分类中。
4. 无项目有系统用例出现在“无所属项目”和对应系统目录中。
5. 同一用例在两个视角修改后保持一致。
6. 旧评审、报告链接能够访问新页面。
7. 查看项目详情不切换项目，进入项目会切换项目。

## 完成标准

- P0/P1 缺陷清零。
- 权限专项、数据迁移和性能验证通过。
- 提供回归报告、已知限制和上线观察指标。
