# task001 P0：数据模型与迁移

## 工作内容

- 为用例补充并回填 `workspace_id`。
- 将 `project_id`、项目模块关系调整为可空。
- 新增业务系统、系统模块及用例系统关系表。
- 建立工作空间、项目、系统及目录所需索引。
- 编写升级、数据校验和必要的回滚脚本。

## 关键规则

- 项目和系统均为空合法，但 `workspace_id` 不允许为空。
- 现有用例保留项目关系；系统关系初始为空。
- 迁移不得改变用例、评审和报告主键。

## 验收标准

- 存量用例全部成功回填工作空间。
- 可保存项目为空、系统为空的用例。
- 重复执行迁移脚本不会产生重复系统关系或破坏数据。
- 校验脚本能输出迁移前后数量、空值和孤儿记录。
