# task003 P1：用例项目与系统双 TAB

## 工作内容

- 在“测试用例 → 用例”下增加“项目”“系统”二级 TAB。
- 项目 TAB 展示项目和项目模块树，并提供“无所属项目”。
- 系统 TAB 展示系统和系统模块树，并提供“待人工分类”。
- 切换 TAB 时同步切换目录树、筛选器和 URL 参数。
- 保留搜索条件时，明确跨 TAB 可复用和需重置的字段。

## 交互规则

- 默认进入项目 TAB。
- 使用 `dimension=project|system` 保留和分享当前视角。
- 切换视角不复制或修改用例数据。
- 用例列表同时展示所属项目和所属系统。

## 验收标准

- 刷新或分享地址后能恢复所选 TAB。
- 无项目用例可在项目 TAB 找到。
- 无系统用例可在系统 TAB 的待人工分类中找到。
- 两个 TAB 打开同一用例时用例 ID 一致。
