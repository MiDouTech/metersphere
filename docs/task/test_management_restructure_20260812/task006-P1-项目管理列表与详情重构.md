# task006 P1：项目管理列表与详情重构

## 工作内容

- 项目管理默认入口调整为项目列表。
- 列表增加快捷进入、项目 ID、项目名称、负责人、成员数、更新时间、状态和操作列。
- 项目名称前和操作列均提供“进入项目”按钮。
- 点击名称或详情进入项目详情，不切换当前项目。
- 将基本信息、权限、菜单、版本、成员、用户组迁入项目详情。
- 详情页顶部增加“进入此项目”。

## 验收标准

- 进入项目管理默认显示项目列表。
- 项目 ID 可展示、搜索且保持稳定。
- 两处进入按钮行为一致，并明确提示切换结果。
- 查看详情不会修改当前项目。
- 当前项目有明确状态，重复进入不会产生异常。
