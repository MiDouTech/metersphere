# task004 P1：用例创建、编辑与分类

## 工作内容

- 将新建、编辑、复制、导入和 AI 生成功能中的项目改为非必填。
- 将所属系统改为非必填。
- 处理无项目情况下的模板、编号、自定义字段和人员选项。
- 支持批量设置/解除所属项目。
- 支持批量设置/解除所属系统及移动系统模块。
- 适配回收站、导入导出和自动化执行入口。

## 产品规则

- 项目和系统均为空时，保存到工作空间未分类集合。
- 选择项目后才加载项目专属模板和字段。
- 清空项目时，对项目专属字段给出明确处理提示。
- 系统分类只修改关系，不生成用例副本。

## 验收标准

- 四种项目/系统组合均可正常保存和编辑。
- 导入模板允许项目、系统留空，并能输出失败原因。
- 批量分类后目录计数和列表即时一致。
- 清空项目不会留下无效项目模块或项目专属引用。
