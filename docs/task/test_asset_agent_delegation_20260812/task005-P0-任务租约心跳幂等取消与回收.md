# task005 - P0 - 任务租约、心跳、幂等、取消与回收

## 状态

部分完成（2026-08-12）：已实现领取、租约令牌、心跳、释放、取消、重试次数与过期回收核心路径；高并发竞态和故障注入验收尚未完成。

## 目标

保证 Agent 领取和执行任务时不重复、不丢失、可取消、可恢复，并在 Agent 掉线后自动回收。

## 实现范围

- 原子领取任务并生成有时效的租约。
- 心跳续租、进度上报和 Agent 健康更新时间。
- 租约过期扫描、任务释放、重排队和最大尝试次数。
- 任务创建、领取、事件、证据和结果提交的幂等规则。
- 暂停、取消、释放与终态提交的并发控制。
- 高风险动作失败不得自动重试。
- 建立补偿扫描、告警和管理操作。

## 验收标准

- 同一任务同一时刻只有一个有效租约持有者。
- 重复领取或提交返回相同业务结果，不产生重复记录。
- Agent 异常退出后在约定时间内回收任务。
- 已取消任务不能继续写入成功终态。
- 并发与故障注入测试通过。
