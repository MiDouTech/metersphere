# task017 - P0/P1 - 旧模型兼容、数据迁移、灰度与回滚

## 状态

部分完成（2026-08-12）：已提供兼容式 DDL/DML、历史资产初始化并保留旧入口；真实数据库迁移演练、组织级灰度开关和回滚演练尚未完成。

## 目标

在不中断现有人工测试、AI 执行和历史报告的前提下迁移到统一模型，并能够按组织或项目灰度和回滚。

## 实现范围

- 旧 `ai_execution_*`、计划执行和附件数据到新模型的映射。
- 新旧 API、MCP Tool、页面路由和报告链接兼容。
- 新写旁路、双读对账、统一入口、旧模型只读和最终下线步骤。
- 按组织、项目、Agent、执行器和环境的功能开关。
- 数据迁移批次、断点、校验、性能和失败补偿。
- 回滚时停止新入口，保留旧执行能力和已写新数据。

## 不应实现

- 首期不删除旧表、旧字段和历史附件。
- 不允许无校验的双写长期存在。

## 验收标准

- 历史任务、结果、附件和报告可查询。
- 灰度开启和关闭不影响非试点项目。
- 迁移前后数量、状态、关联和摘要对账一致。
- 回滚演练完成并形成操作记录。
- 明确旧接口和页面的下线版本与通知方式。
