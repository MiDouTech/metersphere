# task018 - P0/P1/P2 - 全链路测试、验收与发布门禁

## 状态

部分完成（2026-08-12）：后端定向测试、全依赖编译、MyBatis XML 校验、前端类型/路由/生产构建已通过；真实部署环境 E2E、安全、性能、故障和迁移演练尚未执行，不能视为达到发布门禁。

## 目标

建立覆盖领域模型、API、MCP、Bridge、Runner、前端、安全、迁移和故障恢复的验收体系，以真实证据决定是否灰度和发布。

## 测试范围

### 功能闭环

- 人工、定时、CI 和事件创建任务。
- Agent 注册、匹配、领取、心跳、执行、证据、结果和复核。
- 人工登录、暂停、恢复、取消、释放和失败项重试。
- 计划内回写、缺陷关联和报告生成。

### 一致性与故障

- 重复创建、领取、事件、证据和结果提交。
- Agent、Bridge、Runner、数据库、对象存储和网络异常。
- 租约过期、取消与完成竞态、部分成功和补偿扫描。
- 资产变更后历史任务快照保持不变。

### 安全

- 跨组织、项目、环境和任务越权。
- Token 撤销、过期、重放和 Scope 缺失。
- 提示注入、恶意文档、未授权 Origin、文件路径和高风险动作。
- 日志、截图、HAR、错误栈和模型上下文的敏感信息扫描。

### 兼容与性能

- 旧 API、MCP 客户端、执行记录和报告。
- 任务领取 P95、事件积压、证据容量和大项目查询。
- 灰度、数据库迁移和回滚演练。

## P0 验收门禁

- 试点闭环成功率 ≥ 95%。
- 证据完整率 = 100%。
- 幂等场景无重复业务记录。
- Agent 异常退出后按租约回收。
- 无越权和敏感信息泄露。
- 旧人工执行与历史报告正常。

## 交付物

- 自动化测试和测试数据。
- 真实环境端到端执行记录。
- 安全与敏感信息检查报告。
- 数据迁移和回滚演练记录。
- 已知限制、配置手册和发布检查表。

## 完成标准

所有发布门禁有可复核证据；未通过项必须记录责任人、风险、临时措施和关闭条件，禁止将未执行测试标记为通过。
