# task010 - P0 - Agent Bridge 任务通道与进程隔离

## 状态

部分完成（2026-08-12）：保留现有配对、WSS、安装与本地 Provider 边界并更新相关接入基础；统一拉取任务的真实 Bridge 端到端运行尚未验收。

## 目标

在现有设备配对和出站 WSS 基础上，让 Bridge 承担 Agent 在线通道、任务通知、Provider 进程控制和本地隔离。

## 实现范围

- Bridge 注册设备和 Agent 能力，维护在线心跳。
- 接收任务可用、取消、暂停、恢复和密钥轮换通知。
- 按任务创建隔离工作目录、进程和资源限制。
- 上报 Provider 可用性、版本、启动失败和退出原因。
- 支持并发上限、优雅取消、异常清理和恢复。
- 保持官方 Provider 登录与 OS 凭据边界。

## 安全要求

- 不上传 Provider Token、Cookie、密码和凭据文件。
- “进程启动成功”不能等同于“任务执行成功”。
- 默认只读沙箱；扩大写权限必须由任务策略明确授权。

## 验收标准

- WSS 断线重连后任务状态一致，不重复启动进程。
- 取消任务能够终止对应进程而不影响其他任务。
- 不同任务工作目录、日志和进程互相隔离。
- Provider 不可用时任务得到明确 `AGENT_FAILED` 原因。
