# task008 - P0 - Agent 注册、能力声明与最小权限

## 状态

部分完成（2026-08-12）：已有独立 Token、Runner 注册/心跳、能力过滤和项目授权；细粒度环境/工具/风险授权与自动隔离策略尚未全部实现。

## 目标

建立独立 Agent 身份、能力、健康、项目和环境授权，使调度器能够安全选择执行端。

## 实现范围

- Agent 注册、注销、启停、密钥轮换和版本信息。
- 结构化声明能力、任务类型、证据类型和最大并发。
- 项目、环境、工具、操作和风险级别授权。
- Agent、Bridge、Runner 使用不同身份和短期令牌。
- 在线、繁忙、降级、隔离、维护和离线状态。
- 能力验证与准入，不因声明存在就视为生产可用。

## 验收标准

- Agent 只能看到并领取授权范围内的任务。
- 能力不匹配时平台不进行分配。
- 密钥撤销后新请求立即失效，活动租约按策略处理。
- 跨组织、跨项目和跨环境访问测试全部被拒绝。
- 注册、授权和轮换均有审计记录。
