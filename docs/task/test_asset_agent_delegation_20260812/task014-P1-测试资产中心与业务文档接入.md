# task014 - P1 - 测试资产中心与业务文档接入

## 状态

部分完成（2026-08-12）：已实现业务文档、资产版本、关联追溯三条独立页面，支持上传解析、文档/用例版本和来源关系；外部知识库同步及全部资产类型仍未实现。

## 目标

提供面向测试上下文的统一资产入口，并接入业务文档的版本、章节和用例关联。

## 实现范围

- 统一展示文档、用例、数据、环境、公共步骤、接口、证据和缺陷。
- 支持按类型、模块、标签、状态、负责人和关联关系检索。
- 接入 Markdown、Word、PDF、网页或外部知识库同步适配器。
- 保存来源、同步状态、章节索引、发布版本和差异。
- 建立文档章节与用例、任务和缺陷关系。
- 文档发布后产生资产变更事件，供影响分析和触发器使用。

## 非目标

- 不替代通用企业知识库的协同编辑能力。
- 不未经审批自动覆盖正式用例。

## 验收标准

- 可以从业务文档定位关联用例和历史任务。
- 外部文档更新产生新版本，不改变历史任务快照。
- 同步失败、权限失效和内容删除有明确状态。
- 资产列表和关系查询满足项目隔离。
