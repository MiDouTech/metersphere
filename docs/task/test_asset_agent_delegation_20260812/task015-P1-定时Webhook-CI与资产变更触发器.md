# task015 - P1 - 定时、Webhook、CI 与资产变更触发器

## 状态

部分完成（2026-08-12）：已支持 Cron、签名 Webhook、手动触发、并发/错过策略、历史和密钥轮换；专用 CI 适配器与资产变更自动触发尚未实现。

## 目标

以统一触发器生成测试任务，支持周期回归、流水线验证和资产变更驱动测试。

## 实现范围

- Cron 定时触发、时区、错过执行和并发策略。
- Webhook 签名、重放防护、事件过滤和幂等。
- CI 构建、提交、分支和环境信息映射。
- 资产发布/变更触发任务或待审批建议。
- 触发器启停、权限、下次执行、历史和失败告警。
- Agent 创建触发器按受控写操作处理，受 Scope、审批和配额约束。

## 验收标准

- 重复事件只产生一个任务。
- 时区和夏令时边界行为有测试。
- 触发器不能越过项目和环境授权。
- 禁用后不再产生新任务，不影响已创建任务。
- 资产变更默认生成人工确认的范围建议。
