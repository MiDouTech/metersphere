# task001 - P0 - 现有模型、接口、页面与数据盘点

## 状态

已完成（2026-08-12）

盘点结果与兼容矩阵见：`task001-现状盘点与兼容矩阵.md`。

## 目标

识别现有 AI 执行、计划执行、Agent 接入和证据模型，产出新旧能力兼容矩阵，确定哪些结构直接演进、适配或废弃。

## 实现范围

- 盘点 `ai_execution_*`、计划执行、用例执行、附件、审计、Runner 会话相关表和迁移。
- 盘点 `/api/agent/v1`、平台 AI 执行、Runner 内部接口和 OpenAPI。
- 盘点自动化执行工作台、用例 AI 执行入口、计划执行和报告页面。
- 盘点 `metersphere-mcp`、`agent-bridge`、`ai-browser-runner` 的状态、认证和结果协议。
- 标记重复状态、重复结果模型、直接 Mapper 写入和跨模块依赖。
- 形成“保留、演进、适配、只读、下线”结论。

## 产出物

- 数据表与字段矩阵。
- API 与 MCP Tool 矩阵。
- 状态机语义对照表。
- 页面入口和权限矩阵。
- 历史数据量、索引和迁移风险报告。
- 后续任务的明确影响文件清单。

## 不应实现

- 本任务不修改生产模型或删除旧数据。
- 未完成盘点前不得新建第二套任务状态机。

## 验收标准

- 所有现有 AI 执行相关表、接口、页面和组件均有归属结论。
- 已明确 `ai_execution_task` 是演进还是映射到统一任务模型。
- 已识别当前实现与目标协议的所有关键差异。
- 方案经过产品、后端、前端、测试和安全评审。
