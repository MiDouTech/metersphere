# task013 - P0/P1 - 测试证据与人工复核中心

## 状态

部分完成（2026-08-12）：已有任务证据、人工请求、等待/恢复/审批后端路径及详情展示基础；独立证据中心和集中人工复核页面尚未完整实现。

## 目标

集中管理测试证据和需要人工参与的执行节点，让 Agent 能安全暂停并从断点继续。

## 实现范围

- 证据按项目、任务、用例、步骤、类型和时间检索。
- 提供截图、视频、日志、HAR、请求响应和工具调用摘要预览。
- 展示摘要校验、脱敏状态、保留期和访问审计。
- 人工介入支持登录/MFA、数据补充、高风险审批、视觉差异、结果复核和缺陷确认。
- 人工处理结果结构化回写，通知原任务恢复。
- 超时、转派、撤回和审批意见审计。

## 验收标准

- Agent 请求介入后不丢失已完成进度。
- 非任务授权用户不能查看证据或处理介入。
- 证据删除遵循保留策略且保留元数据审计。
- 复核通过、驳回和要求重试均有确定状态流转。
