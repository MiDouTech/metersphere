# task003 - P0 - 测试资产版本与关系模型

## 状态

部分完成（2026-08-12）：已实现文档/功能用例不可变版本、稳定用例身份、关系模型和历史初始化；数据、环境、证据、缺陷等资产类型及完整生命周期尚未覆盖。

## 目标

使业务文档、功能用例、测试数据、环境和证据具备稳定身份、版本和可追溯关联，为任务快照提供可靠来源。

## 实现范围

- 设计统一资产元数据和 `test_asset_version`、`test_asset_relation` 或等效模型。
- 为功能用例建立稳定主记录与不可变发布版本。
- 定义草稿、评审、发布、废弃生命周期。
- 支持需求/文档、用例、任务、证据、缺陷和报告的关系类型。
- 支持内容摘要、创建人、发布时间、变更说明和来源系统。
- 现有用例数据采用兼容方式生成初始版本。

## 不应实现

- 不把所有旧附件机械转换为正式资产。
- Agent 执行偏差不得直接修改发布版本。

## 验收标准

- 已发布版本不可被静默覆盖。
- 计划和任务可引用明确用例版本。
- 可从缺陷追溯到任务、步骤、用例版本和业务文档版本。
- 跨项目资产关系经过授权校验。
- 旧用例查询和编辑能力保持兼容。
