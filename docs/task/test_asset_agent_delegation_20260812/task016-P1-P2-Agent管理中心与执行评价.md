# task016 - P1/P2 - Agent 管理中心与执行评价

## 状态

部分完成（2026-08-12）：Agent 列表、能力与授权、调度队列、执行评价、接入配置五个独立页面已接真实接口；成本/一致性、最低样本和自动准入隔离策略尚未实现。

## 目标

提供 Agent 运维、授权、队列和质量评价能力，为后续能力路由和准入提供数据基础。

## 实现范围

- Agent 列表、详情、在线状态、版本、能力、并发和当前任务。
- 能力与授权页面管理项目、环境、工具和风险权限。
- 调度队列展示待领取、有效租约、心跳、超时、回收和重新分配。
- 统计完成率、误报/驳回率、证据完整率、接管率、耗时、成本和一致性。
- 按业务域、任务类型、Agent 版本和执行器类型分析。
- 建立最低样本量、评价时间窗和准入/隔离策略。

## 关键约束

- 环境失败不能计为 Agent 业务判断失败。
- 低样本量不得直接触发自动禁用。
- 自动路由只能使用经过验证的能力和稳定指标。

## 验收标准

- 指标可追溯到原始任务和人工复核结果。
- 不同失败分类统计口径正确。
- Agent 停用后不获得新任务。
- 权限变更和人工隔离有审计与恢复流程。
