# task007 - P0 - 统一结果、失败分类与步骤级证据

## 状态

部分完成（2026-08-12）：已分离业务结论、失败分类、步骤结果、证据与回写状态；API/性能等执行器的统一结果适配与证据完整率门禁尚未全部完成。

## 目标

统一人工、Browser Agent、API 引擎等执行结果，形成任务—用例—步骤—断言—证据链。

## 实现范围

- 建立任务结果、用例结果、步骤结果、动作、断言和执行偏差结构。
- 建立产品、Agent、环境、数据、用例阻塞和不确定结论分类。
- 证据关联到任务、用例和步骤，保存摘要、类型、脱敏状态和存储引用。
- 复用 MinIO/附件服务，补充分片、容量、保留期和删除策略。
- 结果提交进行 Schema、租约、权限、顺序和证据完整性校验。
- 兼容计划内回写并完成任务汇总对账。

## 完成判定

- 所有要求执行的用例均有终态。
- 失败步骤符合证据策略。
- 结果回写成功。
- 汇总统计与明细一致。

## 验收标准

- 无证据的失败不能被标记为已验收产品缺陷。
- 证据上传或回写失败时任务不能成功。
- 批量部分失败明确表示，不回滚已成功明细。
- 不同执行器结果可进入同一报告。
