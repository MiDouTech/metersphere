# task011 - P0 - Browser Runner 统一任务协议适配

## 状态

部分完成（2026-08-12）：Runner 调度、心跳、控制、结果和证据链已接入统一任务基础；真实浏览器环境闭环、故障恢复和所有动作协议尚未完成验收。

## 目标

将现有 `ai-browser-runner` 接入统一任务、控制、事件、结果和证据协议，完成 P0 浏览器执行闭环。

## 实现范围

- 使用任务短期令牌获取冻结动作和确定性断言。
- 上报领取、准备、登录等待、步骤进度、证据和结果。
- 支持暂停、取消、恢复、租约续期和异常退出。
- 保持独立 Browser Context、Origin 白名单和上传目录限制。
- 截图敏感区域遮罩，日志和网络信息脱敏。
- 高风险动作禁止自动重试，定位自愈不得修改预期结果。

## 不应实现

- Runner 不读取开放式业务文档，不决定任务范围。
- 不执行模型直接生成的 JavaScript、Shell 或任意正则。
- 不绕过验证码、MFA 或扫码登录。

## 验收标准

- 20 条以内功能用例完成任务闭环。
- 人工登录后可以从断点恢复。
- 取消和租约失效后立即停止新动作。
- 未授权域名、文件和动作均被拒绝并记录。
- 步骤结果与截图证据准确关联。
