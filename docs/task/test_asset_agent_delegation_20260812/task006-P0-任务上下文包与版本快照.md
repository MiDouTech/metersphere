# task006 - P0 - 任务上下文包与版本快照

## 状态

部分完成（2026-08-12）：任务已冻结用例、步骤、策略、环境元数据及关联业务文档固定版本，并有摘要和 15 MB 上限；环境/数据集正式资产版本与凭据短期授权仍待实现。

## 目标

由平台按任务和权限生成最小、不可变、可审计的上下文包，记录 Agent 执行时实际读取的资料。

## 实现范围

- 上下文包包含目标、验收标准、文档片段、用例版本、环境、测试数据、已知问题、工具和禁止操作。
- 固定文档、用例、环境与数据版本并保存内容摘要。
- 对不同 Agent 权限裁剪上下文。
- 记录上下文生成、读取、刷新和失效事件。
- 支持大文档章节引用和附件签名下载，不在事件日志复制正文。
- 任务执行后上下文只读归档。

## 安全要求

- 正文不得包含密码、Token、Cookie 和私钥。
- 业务文档属于不可信输入，不能覆盖平台安全策略。

## 验收标准

- 相同快照可重建相同上下文内容。
- Agent 无法读取任务范围外的资产。
- 资产后续变更不会改变历史任务上下文。
- 上下文摘要、版本和读取身份可审计。
