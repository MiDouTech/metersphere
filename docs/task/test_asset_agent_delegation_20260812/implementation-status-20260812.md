# 测试资产与 Agent 任务委派改造实施状态（2026-08-12）

## 结论

本轮已完成可编译、可构建的核心改造代码，形成“业务文档 → AI 用例草稿 → 人工评审 → 正式功能用例 → 不可变资产版本/关系 → 测试任务冻结上下文 → Agent 领取执行 → 结果/证据/评价”的主干能力。

本轮**不等于完整方案已交付或达到生产发布门禁**。task002—task019 均按实际标记为“部分完成”；外部知识库同步、全部资产类型、AI 修改/废弃建议发布、独立证据/复核中心、真实环境端到端、安全/性能/故障/迁移演练仍需后续实施。

## 已实现范围

### 测试资产

- 新增不可变 `test_asset_version` 与 `test_asset_relation`，支持 `DOCUMENT`、`CASE`、`TASK` 等类型扩展。
- 功能用例以 `refId` 作为稳定资产身份，`versionId` 作为业务版本来源；执行仍保留旧用例行 ID 以兼容结果回写。
- 历史已解析文档、现有最新功能用例和已发布 AI 草稿关系使用幂等 DML 初始化。
- 文档解析成功、普通功能用例新增/编辑、审核后的 AI 用例发布会自动登记资产版本。
- AI 发布保存文档到用例的 `DERIVED_FROM` 关系和引用元数据，并拒绝跨项目关系。
- 新增项目隔离的文档、版本、关系查询接口。
- 新增测试资产一级入口及三个独立路由页面：
  - `/test-assets/documents`
  - `/test-assets/versions`
  - `/test-assets/relations`
- 业务文档页支持真实上传、解析状态、资产版本及进入 AI 生成用例；版本/关系页支持筛选、分页和跨页追溯。

### AI 生成用例

- 支持从已授权项目业务文档生成结构化功能用例草稿。
- 支持草稿完整性校验、重复提示、编辑、重新生成、删除、提交评审。
- 新增项目级待评审队列，支持批准、退回修改和驳回。
- 只有审核通过且审核后内容未变化的新增草稿才能发布正式用例。
- 批量发布逐条返回成功/失败；发布前置条件不满足不会错误地把草稿标记为技术失败。
- AI 新增正式用例后生成用例资产版本及文档来源关系。

### 统一任务与 Agent

- 运行状态与业务结论分开存储，支持等待确认、等待人工、暂停、成功、部分成功、失败、取消和过期等路径。
- Agent v1 支持任务检索、能力匹配、领取、租约令牌、心跳、上下文、事件、证据、结果、人机请求、释放和控制。
- 冻结上下文包含用例、步骤、环境元数据、策略以及关联业务文档的固定资产版本；上下文超过 15 MB 时明确拒绝。
- 支持 Cron、签名 Webhook、手动调度，并发/错过策略、历史记录和一次性密钥轮换。
- 支持 Agent/Runner 执行评价与汇总。
- Agent 五个 Tab 均为独立路由和独立页面：
  - `/agent/list`
  - `/agent/capability`
  - `/agent/queue`
  - `/agent/evaluation`
  - `/agent/access`

## 已知未完成项

| 范围 | 当前缺口 | 影响 |
|---|---|---|
| 测试资产 | 测试数据、环境、公共步骤、接口、证据、缺陷尚未全部接入统一资产目录 | 当前资产中心主要覆盖业务文档、功能用例、任务关系 |
| 业务文档 | 尚无 Confluence、语雀、TAPD 等外部知识库同步、差异和权限失效适配器 | 当前支持文件上传与解析，不代表外部同步完成 |
| 用例版本写入 | 普通新增/编辑及 AI 新增已接入；部分批量导入/旁路写入仅由迁移初始化覆盖 | 新导入旁路需继续统一到领域事件 |
| AI 变更建议 | `UPDATE`、`DEPRECATE` 可保存建议数据，但发布领域接入被明确拒绝 | 不能声称已支持修改/废弃正式用例版本 |
| AI 质量 | 具备结构校验与重复提示，但完整相似度、冲突、覆盖缺口和提示注入测试未完成 | 不应以当前校验替代完整质量门禁 |
| 证据/人工复核 | 后端主链已具备，独立证据中心和集中人工复核页面未完成 | 当前主要在执行详情查看和处理 |
| Agent 运营 | 已有基础评价；成本、一致性、最低样本、自动准入/隔离策略未实现 | 暂不应用于自动封禁或高风险路由 |
| Bridge/Runner | 协议和平台侧已扩展，但真实 Agent Bridge + Browser Runner 环境闭环未跑 | 不能据此宣布 P0 闭环成功率达标 |
| 发布门禁 | 未做真实数据库升级/回滚、浏览器 E2E、安全、性能和故障注入 | 当前代码不应直接视为生产可发布 |

## 部署环境验收清单

1. 使用具有对应项目权限的账号登录，逐个点击 Agent 五个 Tab，确认 URL、标题和页面内容同步变化，并验证刷新/前进/后退。
2. 逐个点击测试资产三个 Tab，确认项目隔离、无权限 Tab 隐藏、筛选与分页。
3. 上传 Markdown、Word、PDF，确认解析状态变化并生成文档资产版本。
4. 从业务文档进入 AI 生成用例，确认文档自动选中；完成评审与新增发布，检查 `DERIVED_FROM` 关系。
5. 用发布后的用例创建 Agent 任务，读取任务上下文，确认 `businessDocuments` 固定版本与用例版本一致。
6. 执行领取、心跳、人机等待、恢复、证据、结果回写、评价，验证取消/过期/重试竞态。
7. 在升级前备份数据库，在测试库执行 V44—V46 迁移并校验历史数据，完成回滚演练后才能进入灰度。
