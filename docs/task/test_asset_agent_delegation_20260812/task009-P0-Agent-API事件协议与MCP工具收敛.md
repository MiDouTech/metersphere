# task009 - P0 - Agent API、事件协议与 MCP 工具收敛

## 状态

部分完成（2026-08-12）：Agent v1 已提供任务检索、领取、上下文、事件、产物、结果、人机请求和控制接口；MCP/SDK 全契约回归与协议版本升级策略尚未全部验收。

## 目标

提供稳定的任务查询、领取、上下文、事件、证据、结果、人工介入和控制 API，并让 MCP 继续作为薄适配层。

## 实现范围

- 增加任务搜索、领取、心跳、上下文、事件、证据、结果、人工请求、释放和控制接口。
- 统一认证、Scope、限流、幂等键、游标、错误码和 OpenAPI。
- 事件采用只追加、可排序、可断点续读模型。
- 为 `metersphere-mcp` 增加对应 Tool 与 Schema。
- 现有 `metersphere.execution.*` 通过适配层映射统一任务领域。
- 提供兼容期、废弃提示和客户端版本矩阵。

## 不应实现

- MCP 不负责选择计划、判断重试、计算终态或绕过审批。
- 外部 Agent 不得访问内部 Runner API。

## 验收标准

- REST 与 MCP 对相同请求产生一致业务结果。
- 事件游标重连不丢失已确认事件。
- Scope、限流、Schema 和幂等测试通过。
- 旧 MCP 客户端在兼容范围内继续可用。
