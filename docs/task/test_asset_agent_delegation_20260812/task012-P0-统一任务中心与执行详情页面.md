# task012 - P0 - 统一任务中心与执行详情页面

## 状态

部分完成（2026-08-12）：已提供真实任务队列、筛选、分页和现有执行详情跳转；跨工具旧入口合并、批量运营操作和完整任务详情重构尚未完成。

## 目标

建设统一任务入口和执行详情，替代各测试工具重复的调度和结果入口。

## 实现范围

- 新增全部任务、待审批、待领取、执行中、等待人工、待复核和已完成视图。
- 支持人工、定时、CI、事件和 Agent 来源筛选。
- 创建任务时选择计划/用例、环境、目标、能力、证据和审批策略。
- 执行详情展示任务、用例、步骤、断言、证据、事件、租约和回写状态。
- 支持审批、暂停、取消、恢复、释放、重新分配和失败项重试。
- 用例和计划页面增加“创建测试任务”入口。
- 复用现有自动化执行工作台可用组件并提供旧链接映射。

## 验收标准

- 刷新、项目切换和直接链接能够恢复正确任务上下文。
- 运行状态与业务结论分别展示。
- 无权限操作不显示且后端仍会拦截。
- 事件和进度可断点刷新，不把轮询中断显示为任务失败。
- 移动窄屏至少可完成查看和审批。
