# task012 - P0 - 权限、凭据、域名与高风险动作治理

## 目标

建立 AI Web UI 执行的最小权限、凭据隔离、域名白名单、提示注入防护和高风险动作治理，确保模型与 Runner 不能越权访问或重复危险操作。

## 实施范围

- 完善 `AI_EXECUTION:READ/RUN/CANCEL/LOGIN/ADMIN`，叠加项目、功能用例和测试计划权限。
- Runner 使用短期一次性任务令牌，限定 task/lease、接口、过期时间和上传用途。
- 项目级配置允许域名、协议、环境和 Runner 标签；跨域跳转再次校验。
- 禁止云元数据、回环地址、未授权内网段、任意本地文件和危险下载执行。
- 模型仅看到凭据引用和脱敏账号；无安全凭据服务时统一人工登录。
- 页面内容按不可信输入处理，不能改变系统指令、域名白名单、动作风险或回写目标。
- 动作风险分级；删除、支付、退款、发布、权限变更和批量提交默认禁止或审批。
- 对日志、URL、截图、事件、Prompt 和模型响应实施统一脱敏。
- 所有范围确认、会话接管、登录、风险审批、自愈和回写生成审计记录。

## 验收标准

- 跨项目/跨组织访问在 Controller、Service 和附件层均失败。
- 明文密码、Cookie、Token 和私钥不进入模型上下文和普通日志。
- Prompt Injection 无法改变目标域名、调用未授权工具或跳过确认。
- 高风险动作默认不执行、不自愈重试；审批后仍遵循不可重复策略。
- Runner 任务结束或租约过期后令牌立即失效。

## 测试要求

- 越权、SSRF、DNS Rebinding、跨域重定向、提示注入、令牌重放测试。
- 截图/日志脱敏、恶意上传、MFA/验证码人工处理测试。

## 2026-08-06 实施记录

- 用户接口已使用 `AI_EXECUTION:READ/RUN/CANCEL/LOGIN/ADMIN` 分权，任务、事件和附件读取均再次校验当前项目上下文。
- Runner 注册令牌和租约令牌只保存 SHA-256 摘要；事件、续租和证据上传均校验活动租约，任务进入终态后续租、事件和上传立即拒绝。
- Runner 对每次导航及动作后的页面地址执行精确 Origin 白名单校验；后端拒绝非 HTTP(S)、URL 内嵌凭据、本机和云元数据地址。
- 密钥值只允许通过 Runner 本地 `valueRef` 注入；事件和日志在上报前脱敏，截图上传必须声明已脱敏并通过图片魔数、大小和摘要校验。
- 第一阶段不提供高风险审批执行能力：任何 `riskLevel=HIGH` 动作在任务创建预检和 Runner 契约解析两层直接拒绝，也不会进入自愈或重试。
- 项目模型白名单、AI 并发与 Token 配额已接入现有 `AiGovernanceService`。

仍需在真实部署环境完成 DNS Rebinding、跨项目附件、MFA、恶意上传及令牌重放专项测试；在这些测试完成前，本 task 不标记为生产验收完成。
