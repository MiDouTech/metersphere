# task003 - P0 - 自然语言筛选 DSL 与执行范围确认

> 状态：核心已实现（白名单解析、确定性检索、候选结果和范围哈希已接入；AI Provider 结构化解析与真实数据集 E2E 待完成）

## 目标

将用户自然语言转换为受控筛选 DSL，由 MeterSphere 后端执行确定性查询，并在执行前形成用户可确认、不可漂移的用例范围。

## 实施范围

- 定义 DSL 白名单字段：项目、模块、关键词、标签、优先级、维护人、最近结果、更新时间、风险排除、排序和数量上限。
- 复用 AI Provider 将提示词结构化，使用 JSON Schema 验证，不接受 SQL、脚本或任意表达式。
- 复用 `AgentQueryResolver`、`AgentFunctionalCaseSearchService` 和模块别名能力执行查询。
- 返回原始提示词、DSL、匹配用例、命中原因、排除原因、总数、风险信号和解析置信度。
- 项目缺失、模块重名、低置信度、数量超阈值或高风险时进入确认状态。
- 用户确认后保存最终 `caseIds`、顺序和 `case_snapshot_hash`；运行阶段不重新按提示词搜索。
- 保留手工增删候选用例能力，记录确认前后差异。

## 接口改造

- 扩展 `POST /ai/execution/resolve`。
- 可新增 `POST /ai/execution/resolve/preview`，但应优先兼容现有接口。
- MCP Tool 只做薄封装，不复制解析规则。

## 验收标准

- “用户管理模块 P0 且最近失败，排除删除”可转换并展示为结构化条件。
- 相同 DSL 在相同数据快照下返回稳定结果。
- 模型无法通过提示词注入 SQL、跨项目条件或超出白名单的字段。
- 未确认前不得创建可运行任务；确认后任务范围不随用例列表变化。
- 手工选例不经过模型，后端仍完成权限与有效性复核。

## 测试要求

- 中文自然语言、多条件、否定条件、同名模块、空结果、大结果集测试。
- Prompt Injection、跨项目越权、未知字段和恶意排序测试。
- 模型不可用时允许用户改用手工筛选，不得静默扩大范围。

## 当前实施记录

- 新增保守型 `AgentExecutionNaturalLanguageResolver`，支持优先级、最近结果、标签、风险排除、数量和关键词。
- `resolve` 已返回选择模式、结构化条件、解析置信度、命中原因和 caseId 范围哈希。
- 检索仍由现有服务执行，模型输出无法直接形成 SQL。
- SQL/表达式特征输入会被拒绝进入自然语言筛选。
