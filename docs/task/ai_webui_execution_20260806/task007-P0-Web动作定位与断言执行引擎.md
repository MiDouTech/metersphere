# task007 - P0 - Web 动作、定位与断言执行引擎

> 状态：进行中（V1 动作/定位/断言 DTO 与服务端白名单校验已实现；Playwright 执行适配待 task006）

## 目标

实现受控、确定性优先的 Web UI 动作和断言引擎，确保“操作成功”与“测试通过”严格区分。

## 实施范围

- 实现动作白名单：导航、点击、输入、选择、勾选、上传、键盘、等待、滚动。
- 定位优先级：testId → role/name → label → placeholder/text → 语义邻近 → CSS/XPath。
- 执行前校验元素唯一、可见、启用、可操作以及当前域名。
- 实现文本、可见性、状态、属性、数量、URL 和标题断言。
- 支持步骤/动作/断言独立超时和任务总预算。
- 对提交类动作记录执行前后状态，结果未知时禁止自动重放。
- 模型输出不得直接转为 JavaScript 执行；禁止 `eval` 和任意页面脚本注入。
- 上报 `STEP_STARTED/ACTION_COMPLETED/ASSERTION_FAILED/STEP_COMPLETED` 等结构化事件。

## 验收标准

- 所有首期动作和断言有稳定演示页与自动化测试。
- 多元素命中不随机选择，进入失败或自愈分析。
- 动作成功但断言失败时用例不得通过。
- 文件上传仅允许任务授权文件和大小/类型白名单。
- 页面跳转到未授权域名时立即停止并记录安全事件。

## 测试要求

- 覆盖表单、表格、弹窗、iframe（同源）、上传、动态加载和导航。
- 覆盖重复文本、隐藏元素、遮罩、disabled、跨域 iframe 和恶意下载。
