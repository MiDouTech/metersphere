## 3. 关键偏差修正

1. 业务文档原先出现“详情按项目共享、列表和删除仍按创建人过滤”的语义分裂。现已改为项目级列表和软删除，并防止删除零行仍返回成功。
2. 个人 Token 原先存在无业务逻辑的 test 接口以及多种兼容入口。现已删除，避免后端能力无页面语义。
3. 管理员 Token 治理原先只有后端。现已提供真实页面入口、权限和下载调用。
4. 六类资产原先只有文档/用例/任务骨架。现已接入统一目录和任务固定版本，不再显示空 Tab。
5. 初版补齐中版本/关系接口仍可能按单一旧权限放行。最终实现已将“当前用户可见资产类型”传入 SQL，未指定类型时也不能跨类型读取。
6. 初版个人 Token 权限容器会连带隐藏安装包和管理员治理入口。最终实现已拆成三个独立权限区域。
