# MeterSphere 测试资产与 Agent 偏差补充实施方案

## 1. 范围与豁免

本方案补齐 2026-08-14 静态审计确认的前后端孤岛和纵向切片缺口。系统级用例 Tab 经产品确认列为本次豁免项，保持现状，不纳入实现和验收结论。

本次范围包括：

1. 业务文档详情、下载、重新解析、删除操作闭环。
2. 个人 Agent Token 的前后端权限一致性和无效测试接口清理。
3. 管理员 Token 治理页面及旧 Token 接口治理。
4. 测试数据、环境、公共脚本、接口、执行证据、缺陷六类资产接入。
5. Agent 任务显式资产引用、不可变版本和脱敏上下文。
6. 双向接口孤岛、权限和页面入口发布门禁。
7. 真实存储、浏览器下载和 Bridge 实机验收记录。

## 2. 实现原则

- 原业务模块继续作为唯一事实来源；测试资产中心只做统一目录、版本、关系、追溯和 Agent 上下文，不复制 CRUD。
- 每类资产同时交付页面、API、服务、项目隔离、权限、版本/关系、Agent 上下文和测试。
- 新页面入口最后开放；后端或测试不完整时不得增加空 Tab。
- UI 接口必须有可发现页面和真实调用点；协议、内部、Webhook、Legacy 接口必须分类并有测试或下线时间。
- 任务上下文只能保存脱敏快照。密码、Token、Cookie、私钥及环境密文只保留引用，不写入快照。
- 未执行的真实环境验证必须保持“阻断”，不得用静态检查替代。

## 3. 测试资产模型

统一资产类型：

| 类型 | 事实来源 | 资产中心能力 |
|---|---|---|
| DATASET | 项目文件中的 CSV/JSON/XLS(X) 数据文件 | 查询、版本、引用、任务上下文 |
| ENVIRONMENT | environment | 查询、脱敏版本、任务上下文 |
| COMMON_STEP | custom_function 公共脚本 | 查询、版本、引用、任务上下文 |
| API_DEFINITION | api_definition 最新版本 | 查询、版本、用例/任务关系 |
| EVIDENCE | ai_execution_artifact | 查询、预览/下载、任务/用例/缺陷关系 |
| BUG | bug | 查询、版本、用例/任务/证据关系 |

`test_asset_version` 保存不可变快照和 SHA-256；`test_asset_relation` 保存资产之间的有向关系。目录查询触发幂等版本协调，领域写入逐步改为事件驱动，但不得修改历史版本。

## 4. 统一 API

- `GET /test-assets/catalog`：按项目、类型、关键字、状态分页查询六类资产。
- `GET /test-assets/catalog/{type}/{id}`：查询资产详情和当前固定版本。
- `GET /test-assets/versions`、`GET /test-assets/relations`：复用现有版本和关系查询。
- `POST /functional/case/ai/document/download|retry|delete`：由业务文档页面调用。
- `/personal/agent-tokens/**`：按 READ/CONNECT/REVOKE 权限保护。
- `/admin/agent-tokens/**`：由系统设置 Token 治理页调用。

任务创建请求增加 `assetRefs[{assetType,assetId,versionId}]`。后端校验项目归属并固定版本；任务上下文增加 `assets`，每项包含类型、稳定 ID、版本 ID、哈希和脱敏快照。

## 5. 权限矩阵

| 能力 | 读权限 | 写权限 |
|---|---|---|
| 测试数据 | PROJECT_FILE:READ | 资产中心只读，编辑跳转原模块 |
| 环境 | PROJECT_ENVIRONMENT:READ | 资产中心只读，编辑跳转原模块 |
| 公共脚本 | PROJECT_API_SCENARIO:READ | 资产中心只读，编辑跳转原模块 |
| 接口 | PROJECT_API_DEFINITION:READ | 资产中心只读，编辑跳转原模块 |
| 执行证据 | AI_EXECUTION:READ | Runner/Agent 机器身份上传 |
| 缺陷 | BUG:READ | 资产中心只读，编辑跳转原模块 |
| 业务文档下载 | FUNCTIONAL_CASE_AI:READ | 无 |
| 业务文档重试/删除 | FUNCTIONAL_CASE_AI:READ | FUNCTIONAL_CASE_AI:UPLOAD |
| 个人 Token 查询 | SYSTEM_PERSONAL_AI_AGENT:READ | 无 |
| 个人 Token 创建/更新/启停 | SYSTEM_PERSONAL_AI_AGENT:READ | SYSTEM_PERSONAL_AI_AGENT:READ+CONNECT |
| 个人 Token 删除/撤销 | SYSTEM_PERSONAL_AI_AGENT:READ | SYSTEM_PERSONAL_AI_AGENT:READ+REVOKE |
| Token 治理 | SYSTEM_USER:READ | SYSTEM_USER:UPDATE |

实际权限常量以仓库已有 PermissionConstants 为准；不存在的组合权限不得临时降级成仅登录可调用。

## 6. 页面

测试资产增加六个非空页面：测试数据、测试环境、公共步骤、接口资产、执行证据、缺陷资产。页面统一支持筛选、分页、版本、关系和跳转事实来源；证据支持安全预览/下载。

业务文档操作列增加详情、下载、失败重试和删除。系统设置 Agent 集成增加管理员 Token 治理区域，普通用户不可见。

## 7. 发布门禁

接口清单由扫描 Controller 和前端请求自动生成；人工 manifest 只保存类型、责任人和例外，不再决定扫描范围。门禁必须检查：

1. UI 后端端点存在前端 API、页面调用和路由/组件入口。
2. 前端 API 方法被业务页面实际引用，禁止以未使用封装冒充入口。
3. 写接口有权限注解或明确机器身份；写按钮具有相同权限。
4. PROTOCOL/WEBHOOK/INTERNAL 有测试；LEGACY 有责任人、原因和到期日。
5. 空 Tab、占位页和仅提示“暂未开放”的新增能力不能通过 UI 验收。

## 8. 完成定义

只有文档、代码、迁移、权限、后端测试、前端类型检查、浏览器流程和真实环境状态一致时才可标记完成。真实对象存储、浏览器大文件下载、Bridge 实机和代码签名未验证时，继续作为发布阻断项。
