# task008 - P0 缺陷管理前端体验优化

## 目标

按已确认预览方案调整缺陷管理列表和缺陷详情抽屉：详情标题展示缺陷 ID，缺陷名称进入详情内容；列表状态改为统一圆角标签；删除缺陷详情评论 Tab。

## 范围

- `frontend/src/views/bug-management/`
- 缺陷管理列表
- 缺陷详情抽屉
- 缺陷详情 Tab 配置
- 缺陷状态样式映射

## 实现要点

### 1. 抽屉标题区

当前缺陷详情顶部展示缺陷名称，改为展示缺陷 ID。

目标展示：

```text
100005
```

规则：

- 抽屉顶部主标题只显示缺陷 ID。
- 不再在标题区显示缺陷名称。
- ID 使用列表中的展示编号，例如 `100005`，不是数据库内部 UUID 或雪花 ID。

### 2. 详情 Tab 内容区

将原详情区中的“缺陷信息”区块调整为“缺陷名称”。

目标结构：

```text
缺陷名称
商品查询存在同级码数据时展示异常

缺陷内容
……
```

规则：

- 将原区块标题“缺陷信息”修改为“缺陷名称”。
- 去掉区块内部重复的“缺陷名称”字段 label。
- “缺陷名称”标题下直接展示缺陷名称内容。
- “缺陷内容”保持在缺陷名称下方。
- 查看态和编辑态结构保持一致。

### 3. 列表状态样式

状态列改为标签/按钮式样式，参考缺陷详情右侧“责任人”按钮或标签视觉。

| 状态 | 样式建议 |
|---|---|
| 新建 | 蓝色浅底圆角标签 |
| 处理中 | 橙色浅底圆角标签 |
| 已解决 | 绿色浅底圆角标签 |
| 非缺陷 | 灰色浅底圆角标签 |
| 已关闭 | 灰色或深灰浅底圆角标签 |

规则：

- 状态不再使用普通文本样式。
- 状态标签需具备统一高度、圆角和内边距。
- 状态颜色映射集中维护。
- 只改变展示，不改变状态枚举、流转规则和后端字段。

### 4. 删除评论 Tab

缺陷详情 Tab 调整为：

```text
详情 ｜ 用例 ｜ 变更历史
```

删除：

```text
评论
```

兼容规则：

- 前端 Tab 配置中移除评论 Tab。
- 如果用户本地缓存的 active tab 为评论 Tab，打开详情时自动回退到 `详情`。
- 后端评论接口本次不删除。

## 验收标准

- 缺陷详情顶部显示缺陷 ID，不显示缺陷名称。
- 详情 Tab 中按“缺陷名称 / 缺陷内容”顺序展示。
- 缺陷详情无“评论”Tab。
- 旧缓存评论 Tab 不导致详情空白。
- 缺陷列表状态为统一圆角标签样式。
- 查看态、编辑态和刷新后布局一致。
