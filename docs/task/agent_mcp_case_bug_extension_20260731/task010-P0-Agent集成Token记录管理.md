# task010 - P0 Agent 集成 Token 记录管理区

## 目标

在系统设置 - 系统 - Agent 集成页面新增“我的 Agent Token”区域，集中展示和管理当前用户创建的 Token 记录；保留 Token 密钥仅创建时展示一次的规则，并将原说明文字下移到记录区下方。

## 范围

- `frontend/src/views/setting/`
- Agent 集成页面
- Agent Token 列表 API
- Agent Token 创建、启用/停用、删除 API
- Token 一次性密钥展示弹窗

## 页面结构

页面位置：

```text
系统设置 > 系统 > Agent 集成
```

目标结构：

```text
我的 Agent Token                         [创建 Token]

名称 | Scope | 项目范围 | 创建时间 | 最后使用时间 | 状态 | 操作

使用说明
原说明文字……
```

操作项：

```text
查看 ｜ 停用/启用 ｜ 删除
```

## 实现规则

- 用户只能看到并管理自己创建的 Token。
- 已创建 Token 不展示密钥明文。
- Token 密钥仍然只在创建成功时显示一次。
- 创建成功弹窗中保留一次性密钥展示和复制提醒。
- Token 列表支持状态展示，例如 `启用`、`已停用`。
- 删除 Token 前需要二次确认。
- 停用 Token 后，该 Token 不能继续调用 Agent MCP 服务。
- 重新启用 Token 时仍不展示密钥明文。
- 当前页面已有说明文字移动到 Token 记录区下方。
- 主操作区优先展示 Token 记录，说明信息作为辅助内容。

## 建议字段

| 字段 | 说明 |
|---|---|
| 名称 | 用户创建 Token 时填写的名称 |
| Scope | Token 授权范围 |
| 项目范围 | 全部项目或项目白名单 |
| 创建时间 | Token 创建时间 |
| 最后使用时间 | 最近一次调用时间，无记录显示 `-` |
| 状态 | 启用、已停用 |
| 操作 | 查看、停用/启用、删除 |

## 验收标准

- Agent 集成页面上方展示“我的 Agent Token”记录表。
- 当前用户只能看到自己创建的 Token。
- Token 密钥只在创建成功时显示一次，列表中不展示明文密钥。
- 停用后 Token 不可继续调用 MCP 服务。
- 重新启用 Token 不展示密钥。
- 删除前有二次确认。
- 原说明文字位于 Token 记录区下方。
