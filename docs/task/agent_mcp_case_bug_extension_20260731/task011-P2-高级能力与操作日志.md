# task011 - P2 高级能力与操作日志

## 目标

在 P0/P1 基础闭环稳定后，扩展高级能力，包括文件库关联、用例和缺陷导入导出、永久删除、外部缺陷平台同步和 Agent 操作日志前端展示。

## 范围

- `backend/services/agent-integration/`
- 文件库关联和转存
- 用例导入导出
- 缺陷导入导出
- 永久删除 Scope
- 外部缺陷平台同步
- Agent 操作日志前端页面

## 高级能力

1. 文件库关联和转存。
2. 用例及缺陷导入导出。
3. 永久删除，默认关闭。
4. 外部缺陷平台同步，使用独立高风险 Scope。
5. Agent 操作日志前端展示。

## 实现规则

- 永久删除必须使用独立 Scope，默认不授予。
- 永久删除必须带 `confirm=true` 和二次风险确认字段。
- 外部缺陷平台同步必须使用独立高风险 Scope。
- 导入导出任务必须具备任务状态查询能力。
- Agent 操作日志不得展示明文 Token。
- 操作日志支持按用户、项目、工具、资源、时间和结果筛选。

## 验收标准

- 高风险 Scope 默认关闭。
- 永久删除不能通过普通删除 Scope 执行。
- 导入导出任务状态可查询，失败原因明确。
- Agent 操作日志可在前端查询，不泄露 Token 明文。
- 外部缺陷平台同步失败不会影响本地核心数据一致性。
