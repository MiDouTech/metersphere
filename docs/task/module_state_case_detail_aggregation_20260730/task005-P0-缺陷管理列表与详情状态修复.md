# task005 - P0 缺陷管理列表与详情状态修复

## 目标

修复缺陷管理中切换模块后列表空白、详情残留的问题。缺陷管理返回时应恢复列表数据；打开缺陷详情后切换至其他模块，详情不应继续展示。

## 范围

- 缺陷管理列表页面
- 缺陷详情抽屉/详情页
- 路由监听与 `keep-alive` 生命周期
- 列表刷新和详情关闭策略

## 实现要点

1. 缺陷管理页面被激活时刷新列表数据，但不清空筛选、排序、分页。
2. 从缺陷管理切换到非缺陷模块时：
   - 关闭缺陷详情
   - 清理当前详情 ID
   - 不影响列表筛选和分页状态
3. 从其他模块返回缺陷管理时：
   - 自动刷新列表
   - 若原列表有数据，不得显示空白
4. 修复详情抽屉路由监听，只有缺陷管理相关路由允许详情继续显示。
5. 数据删除、权限丢失时提示并回退到列表。

## 验收标准

- 缺陷管理存在缺陷时，切到其他模块再返回，列表正常显示。
- 不需要手动刷新才能看到原有缺陷。
- 打开缺陷详情后切换到其他模块，详情不会残留显示。
- 返回缺陷管理时，列表状态保持，数据刷新。
