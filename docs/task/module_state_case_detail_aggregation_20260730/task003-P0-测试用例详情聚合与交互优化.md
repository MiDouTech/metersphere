# task003 - P0 测试用例详情聚合与交互优化

## 目标

将测试用例详情从多个分散 Tab 调整为聚合展示，在标题下展示评审、测试计划、个人执行进度，并优化 TEXT 模式提缺陷、前置条件、备注和进度条交互。

## 范围

- `caseDetailDrawer`
- `tabDetail`
- 评论组件内嵌
- 评审/测试计划概览接口或聚合数据
- 个人执行进度展示

## 实现要点

1. 标题下新增关联摘要：
   - `评审：评审计划（ID）【状态样式】`
   - `测试计划：测试计划（ID） 百分比进度 进度条`
   - `个人执行进度：x/y 分段进度条`
2. 多评审、多测试计划默认展示最近 2 条，其余可展开。
3. 进度条 hover 显示详情：
   - 状态
   - 数量
   - 占比
4. 移除或隐藏详情中的独立 Tab：
   - 依赖关系
   - 评论
   - 用例评审
   - 测试计划
5. “用例” Tab 文案调整为“前置用例”，内部 key 可保持不变。
6. 评论内嵌到详情内容下方，支持发布、回复、删除、附件和分页。
7. TEXT 模式“提缺陷”按钮参考添加附件按钮样式，放在页面右侧并适当放大。
8. 前置条件、备注内容字体颜色加黑，参考“前置条件”标题色。

## 验收标准

- 用例详情标题下能看到评审、测试计划和个人执行进度。
- 测试计划进度条 hover 显示明细。
- TEXT 模式提缺陷按钮在预期结果区域右侧，样式与附件按钮一致且尺寸更醒目。
- 前置条件和备注内容可读性增强。
- 旧 Tab 配置不会导致详情空白。
- 评论发布后局部刷新，不关闭详情、不重置滚动位置。
