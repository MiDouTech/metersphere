# task004 - P0 测试计划关联用例列表对齐

## 目标

测试计划详情中关联的用例列表，在字段、展示、筛选、排序、UI 行为上与测试用例模块中的用例列表保持一致。

## 范围

- 测试计划关联用例列表前端表格
- 测试计划关联用例后端查询 DTO/Response
- 排序字段映射
- 用户名、时间、标签、执行状态、评审状态等展示

## 实现要点

1. 对齐测试用例模块默认字段：
   - 用例名称
   - 所属模块
   - 评审状态
   - 执行结果
   - 最后执行时间
   - 责任执行人
   - 最后执行人
   - 标签
   - 缺陷数
   - 创建人/创建时间
   - 更新人/更新时间
2. 支持与测试用例模块一致的字段格式化：
   - 时间格式
   - 用户名展示
   - 标签样式
   - 状态样式
3. 后端排序字段必须使用安全映射，禁止直接拼接未校验字段。
4. 前端表格缓存 key 升级，避免旧列配置隐藏新增默认列。
5. 若计划关联表缺少独立最后执行人字段，需明确使用来源并补充后续模型优化项。

## 验收标准

- 测试计划关联用例列表与测试用例模块字段一致。
- “最后执行时间”可展示、可排序。
- 状态、标签、时间格式一致。
- 旧用户列配置不会导致新增字段完全不可见。
- 后端 SQL 无注入风险，编译通过。
