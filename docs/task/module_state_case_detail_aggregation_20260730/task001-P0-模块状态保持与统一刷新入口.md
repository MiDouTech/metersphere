# task001 - P0 模块状态保持与统一刷新入口

## 目标

为动态业务页面建立统一刷新入口和状态保持协议。用户切换一级/二级模块再返回时，页面应自动刷新最新数据，但保持原有视图状态。

## 范围

- `frontend/src/layout/page-layout.vue`
- 路由 `meta` 配置
- 公共刷新组件和 hook
- 测试用例、测试计划、缺陷管理的首批接入
- 后续动态页面接入清单

## 实现要点

1. 新增公共刷新组件，例如 `MsModuleRefresh`。
2. 新增 `useModuleRefresh` 或等价刷新协议，统一处理：
   - `initial`
   - `activated`
   - `data-change`
   - `manual`
3. 页面刷新时必须保留：
   - 树展开节点
   - 当前选中节点
   - 筛选条件
   - 排序
   - 分页
   - 滚动位置
   - 展示模式
   - 已打开详情及详情 Tab
4. 调整 `keep-alive` 策略，业务模块切换不销毁需要保留状态的组件。
5. 将页面初始化逻辑拆分为：
   - `initializeViewState`
   - `refreshData`
6. 建立动态页面刷新接入清单，标注已接入、复用父级刷新或不适用原因。

## 验收标准

- 测试用例展开多级树、设置筛选/排序/分页后，切换到测试计划再返回，状态保持且数据刷新。
- 缺陷管理列表切换模块再返回，列表不空白。
- 手动点击刷新按钮后，业务数据刷新，视图状态不重置。
- 自动刷新和手动刷新走同一套刷新逻辑。
- 页面不可见时合并刷新请求，重新激活后只刷新一次。

## 非目标

- 不重构所有业务页面的数据模型。
- 不引入全局页面 reload。
