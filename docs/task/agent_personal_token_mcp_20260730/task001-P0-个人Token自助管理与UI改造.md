# task001 - P0 个人 Token 自助管理与 UI 改造

## 目标

让所有正常登录用户都可以自助创建和管理代表本人身份的 Agent Token，并在 Agent 集成页面提供明确的创建入口和接入引导。

## 范围

- Agent 集成页面
- Token 创建/列表/禁用/启用/轮换/删除交互
- 当前用户身份提示
- Token scope 中文化
- 创建成功一次性展示 Token 和 MCP 配置

## 实现要点

1. 页面提供明显的“创建 Token”入口。
2. 创建表单不允许选择 `userId`，后端强制绑定当前登录用户。
3. 普通用户可选择权限范围，包括：
   - 全部 Agent 权限
   - 只读访问
   - 测试执行
   - 用例管理
   - 缺陷管理
   - 项目管理
4. scope 在页面上使用中文业务描述，不直接把内部枚举作为主文案。
5. 创建成功弹窗展示：
   - 完整 Token，一次性展示
   - 可复制 Token
   - 可复制 MCP 配置
   - 下载技能包入口
   - “我已保存 Token”确认
6. 删除“解压后按 INSTALL.md 配置本机 mcp.json”等本地 stdio 包提示。
7. Token 列表只展示当前用户自己的 Token。

## 验收标准

- 普通用户无需系统管理权限即可创建本人 Token。
- 请求中伪造 `userId` 不生效。
- 用户无法查看或操作他人 Token。
- 完整 Token 关闭弹窗后不可再次查看。
- 页面存在创建入口，并能进入创建流程。
- 页面文案明确说明 Token 权限不超过当前用户在 MeterSphere 中已有权限。
