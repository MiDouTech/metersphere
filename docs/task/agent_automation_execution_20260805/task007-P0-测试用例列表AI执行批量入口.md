## 目标

在功能用例列表批量操作区新增【AI执行】入口，允许用户对已勾选的有效功能用例创建自动化执行任务。

## 实现范围

- 在功能用例列表批量操作区新增【AI执行】按钮。
- 只有勾选至少一条有效用例且拥有 `AI_EXECUTION:RUN` 权限时按钮可用。
- 点击后打开执行确认弹窗，不立即执行。
- 确认弹窗展示：
  - 选中用例范围
  - 测试计划
  - 目标环境
  - 访问地址
  - 浏览器类型
  - 登录方式
  - 高风险提示
- 创建任务时前端只传稳定 `caseId` 列表和必要上下文，后端重新校验项目、权限、删除状态及数量限制。
- 创建成功后跳转 `/bug-management/automation-execution` 并定位到 `executionTaskId`。

## 不应实现的内容

- 不允许未勾选用例时执行。
- 不允许前端传完整用例数据给后端直接信任。
- 不允许跳过确认弹窗直接执行。

## 验收标准

- 勾选有效用例后【AI执行】可用；未勾选或无权限时不可用。
- 确认弹窗信息准确，数量和用例列表与选择一致。
- 后端权限复核失败时任务不创建。
- 创建成功后自动跳转并能在自动化执行页面看到对应任务。

## 验证要求

- 功能用例列表 UI 验证。
- 批量选择和跨页选择验证。
- 权限隐藏 / 禁用验证。
- 任务创建与跳转联调。
