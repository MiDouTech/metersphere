# task011 - P2 - 凭据引用、域名白名单、高风险动作治理

## 状态

未开始

## 目标

补齐自动化执行的安全治理能力，确保凭据、访问域名、高风险操作、配额和审批均受到平台策略控制。

## 实现范围

- `ai_credential_reference` 仅保存密钥管理系统引用，不保存明文。
- 凭据按组织、项目、环境、域名隔离。
- 目标域名使用项目白名单。
- 默认禁止内网探测、任意文件访问和非授权跨域跳转。
- 删除、支付、发布、权限修改、批量修改等高风险动作默认禁止。
- 确需执行高风险验证时，要求隔离环境、显式审批和审计记录。
- 支持任务数、用例数、执行时长、附件容量、模型费用等配额控制。

## 不应实现的内容

- 不允许把凭据明文传给模型。
- 不允许 Runner 越过域名白名单访问任意地址。
- 不允许高风险动作默认放行。

## 验收标准

- 凭据明文不进入数据库、模型上下文、普通日志、截图和导出文件。
- 非白名单域名访问被拦截并记录审计。
- 高风险动作被拦截或要求显式审批。
- 超过配额的任务无法创建或无法继续执行，并返回明确原因。

## 验证要求

- 凭据引用读写测试。
- 域名白名单拦截测试。
- 高风险动作审批测试。
- 配额限制测试。
- 日志与截图脱敏检查。
