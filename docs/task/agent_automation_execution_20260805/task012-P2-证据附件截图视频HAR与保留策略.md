# task012 - P2 - 证据附件、截图视频 HAR 与保留策略

## 状态

未开始

## 目标

完善自动化执行证据采集与保留策略，支持失败定位、执行审计和结果回写附件关联。

## 实现范围

- 失败步骤默认保存截图、脱敏 URL、错误摘要和关键控制台信息。
- 按项目策略启用视频、HAR、DOM 快照。
- 证据使用现有临时附件和 MinIO 服务保存。
- 证据需关联任务、用例、步骤、事件日志和回写结果。
- 支持证据保留期限、单任务容量和项目总容量配置。
- 支持证据下载、预览和清理。

## 不应实现的内容

- 不允许截图和 HAR 中保留明文密码、Token、Cookie、私钥。
- 不允许证据未落库时把任务标记为成功。
- 不允许附件孤儿数据长期无清理策略。

## 验收标准

- 失败步骤可从任务详情定位截图、日志和错误摘要。
- 计划内/计划外结果均能关联执行证据。
- 证据超过保留期限或容量限制后可按策略清理。
- 证据下载权限与项目权限一致。

## 验证要求

- 截图、视频、HAR、DOM 快照策略测试。
- MinIO 上传和附件关联测试。
- 证据脱敏测试。
- 保留期限和容量清理测试。
