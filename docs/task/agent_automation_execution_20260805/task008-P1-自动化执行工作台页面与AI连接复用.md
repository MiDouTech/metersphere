# task008 - P1 - 【自动化执行】工作台页面与 AI 连接复用

## 状态

未开始

## 目标

实现缺陷管理下的【自动化执行】工作台页面，支持 AI 对话、范围确认、执行视窗、步骤进度、日志、证据和结果回写状态展示。

## 实现范围

- 页面布局采用左侧 AI 对话区 35%、右侧执行视窗与日志区 65%。
- 左侧展示：
  - 会话历史
  - 项目与用例解析结果
  - 执行范围确认
  - 登录提示
  - `连接AI`、`停止任务`
  - 执行要求输入框和发送按钮
- 右侧展示：
  - 任务状态、项目、计划、环境、Agent、开始时间
  - Runner 实时画面或关键截图
  - 用例和步骤执行进度
  - `INFO/WARN/ERROR` 日志筛选
  - 成功、失败、阻塞、未执行数量
  - 回写状态和失败原因
  - 暂停、停止、重试失败项、下载日志
- 复用【生成用例】模块的 Provider Selector、系统模型、个人模型和 OAuth/Agent 网关连接能力。
- 支持通过 `executionTaskId` 定位任务详情。

## 不应实现的内容

- 不维护第二套 AI Provider 配置。
- 不在前端实现范围选择业务规则。
- 不显示未脱敏的密码、Token、Cookie、私钥。

## 验收标准

- 页面可实时展示任务、步骤、日志、证据和回写状态。
- `executionTaskId` 直接进入页面后可恢复任务视图。
- AI 连接状态与【生成用例】模块配置一致。
- 敏感信息在画面、日志和导出内容中均不明文显示。

## 验证要求

- 页面布局和交互验证。
- Provider Selector 复用验证。
- 任务详情恢复验证。
- 日志筛选和下载验证。
