# task013 - P0/P1/P2 - 全链路测试、验收与交付自检

## 状态

未开始

## 目标

对 Agent 自动化执行改造进行端到端验证，确保任务选择、执行、日志、证据、回写、安全和异常处理符合方案要求。

## 实现范围

- 覆盖以下主链路：
  - 外部 Agent 通过 MCP 查询项目、计划、用例并创建执行任务。
  - 平台【自动化执行】页面发起任务并确认范围。
  - 功能用例列表勾选用例后通过【AI执行】创建任务。
  - Runner 执行用例并上报事件、证据和结果。
  - 计划内结果回写测试计划。
  - 计划外结果回写功能用例最近结果和 Agent 日志。
- 覆盖以下异常链路：
  - 未指定项目。
  - 多项目、多计划、多用例歧义。
  - 大范围执行确认。
  - 高风险动作拦截。
  - 无会话无凭据进入 `WAITING_LOGIN`。
  - Runner 断线、取消、重试。
  - 单条回写失败导致 `PARTIAL_SUCCESS`。
- 输出自检记录，包含修改范围、验证命令、验证结果和未完成事项。

## 不应实现的内容

- 不允许用 Mock 结果冒充真实端到端验证。
- 不允许只验证前端页面而跳过后端权限和回写链路。
- 不允许把未验证内容标记为已完成。

## 验收标准

- 方案第 15 节所有验收项均有对应测试或验证记录。
- P0 闭环至少在隔离测试环境完成 20 条以内功能用例验证。
- 所有失败、取消、部分成功状态均与数据库、页面和日志一致。
- 敏感信息不会出现在模型上下文、普通日志、截图、HAR 或导出文件中。
- 交付说明明确列出已完成、部分完成、未完成和未验证内容。

## 验证要求

- 后端单元测试和集成测试。
- 前端组件和页面联调测试。
- MCP Tool 调用测试。
- Runner 端到端执行测试。
- 权限、安全、审计和脱敏专项测试。
