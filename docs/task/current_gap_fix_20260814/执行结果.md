## 2. 已完成实现

- 个人 Agent Token 编辑统一为 PATCH，管理员状态筛选贯通前端参数、DTO、Service 和 Mapper，并保留本人 Token 归属校验。

- 执行工作台支持远程搜索环境、最多 50 个多类型资产的添加和移除；后端校验环境唯一性、项目归属和资产版本，失败时事务整体回滚。
- 图片和安全文本证据支持安全预览，HTML、SVG、二进制和未脱敏证据不内联；证据、步骤、用例、任务和缺陷关系可追溯。
- 测试资产默认路由按权限选择首个可访问 Tab，业务文档列表、详情和下载权限统一，详情增加项目所有权校验。
- 个人中心 Agent Token 入口和操作按 READ、CONNECT、REVOKE 权限控制。
- UI/API 闭环门禁增加 HTTP 方法与路径检查，并由已分类业务根路由自动定位相关 Controller；manifest 不再维护前后端文件扫描清单。
