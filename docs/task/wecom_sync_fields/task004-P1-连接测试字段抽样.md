## 1. 任务目标

在企微同步「测试连接」成功后，抽样拉取少量成员，提前暴露「Token 通但无手机/邮箱权限」问题，避免全量同步后才发现。

## 2. 任务清单

### 2.1 后端

- [x] `OrgWecomSyncConfigService`（或等价配置服务）测试连接成功后：  
  - 拉取根部门 1 页成员（或前 N 条，N≤20）  
  - 计算并返回：`hasMobileSample` / `hasEmailOrBizMailSample` /（可选）`sampleSize`  
- [x] 抽样失败不导致「连接失败」；降级为警告字段（连接本身仍成功）  
- [x] 不落库成员数据  

### 2.2 前端

- [x] 配置抽屉展示提示：  
  - 无手机样本 → 检查「获取成员手机号」  
  - 无邮箱/企业邮箱样本 → 检查邮箱相关通讯录权限  
- [x] 有样本则显示成功提示或静默
