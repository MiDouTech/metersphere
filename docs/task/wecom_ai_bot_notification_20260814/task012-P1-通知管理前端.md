# task012 - P1 企业微信通知管理前端

> 状态：前后端入口闭环并通过静态检查，待浏览器联调验收  
> 前置依赖：task004、task006、task007、task011  
> 阻塞任务：task015  
> 关联方案：§9

## 1. 任务目标

在“系统设置 → 消息通知”提供 Bot 配置、群目标、通知规则和发送日志页面，并明确区分智能机器人、自建应用、通讯录同步和群 Webhook。

## 2. Bot 配置页

- [ ] 名称、BotID、Secret 配置状态、启用开关；
- [ ] Secret 密码框不回填原值；
- [ ] ONLINE/OFFLINE/AUTH_FAILED 等状态；
- [ ] 最近认证、心跳和脱敏错误；
- [ ] 测试连接、测试个人消息；
- [ ] 轮换 Secret 的风险提示。

## 3. 群会话页

- [ ] chatid 脱敏、备注、首次/最近发现时间；
- [ ] 启用/禁用；
- [ ] 测试发送；
- [ ] 空状态引导：加 Bot 入群并 @Bot；
- [ ] 不提供自由填写 chatid 的输入框。

## 4. 通知规则页

- [ ] 类型：缺陷临期、报告生成、通用 Cron；
- [ ] 不同类型动态展示合法配置项；
- [ ] 对象：用户、业务角色、项目成员、角色/用户组、群；
- [ ] 时间：提前量、间隔、Cron、时区、有效期；
- [ ] 模板变量插入、预览和长度提示；
- [ ] 停止条件；
- [ ] 下次执行时间、启停、立即执行；
- [ ] 报告通知默认“项目全部有效成员”；
- [ ] 缺陷通知默认“处理人 + 创建人”。

## 5. 日志页

- [ ] 状态、类型、目标类型、规则、时间筛选；
- [ ] 错误码和脱敏错误详情；
- [ ] 可重试消息人工重试；
- [ ] 不展示 Secret、完整授权头和非必要完整正文。

## 6. 验收标准

- [ ] 无权限用户看不到入口或操作按钮；
- [ ] Secret 永不从服务端回显；
- [ ] 三种规则都能完成创建、预览、启停；
- [ ] 非法时间/对象组合在提交前提示；
- [ ] 状态与后端事实一致；
- [ ] 中英文文案和基础可访问性完整。
