# task010 - P1 通用 Cron 周期通知

> 状态：代码实现完成，待 Quartz 集成环境验收  
> 前置依赖：task007、task011  
> 阻塞任务：task015  
> 关联方案：§4.2.3、§8.3

## 1. 任务目标

实现 `CUSTOM_CRON` 通知类型，让管理员配置个人/群目标、消息模板、Cron、时区、有效期和停止条件。

## 2. 配置项

- 名称和作用域；
- Cron 表达式；
- 显式时区，默认 `Asia/Shanghai`；
- 开始/结束时间；
- 个人、群聊或 BOTH；
- 指定用户、项目成员、项目角色、用户组、已启用群；
- Markdown 模板；
- misfire 策略，默认 `DO_NOTHING`；
- 启停和立即执行。

## 3. 任务清单

- [ ] 复用 `ScheduleManager` 创建/更新/删除 Quartz Job；
- [ ] JobDataMap 只保存 ruleId；
- [ ] 执行时重新加载规则和对象；
- [ ] Cron、时区、有效期校验；
- [ ] 计算并返回 nextFireTime；
- [ ] 修改规则后重建 Job；
- [ ] 规则、项目删除时清理 Job；
- [ ] 立即执行同样写 Outbox；
- [ ] 多实例 Quartz 不重复生成 triggerKey；
- [ ] 禁止自定义脚本、SQL 和任意 URL 请求。

## 4. 验收标准

- [ ] 指定时区下按 Cron 准确执行；
- [ ] 个人和群目标均可选择；
- [ ] 禁用后不再触发；
- [ ] 服务恢复后不集中补发历史提醒；
- [ ] 立即执行有独立 triggerKey 和完整日志；
- [ ] 同一触发点不会重复投递同一目标。
