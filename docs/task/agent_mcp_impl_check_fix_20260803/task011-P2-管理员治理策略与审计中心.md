# task011 - P2 管理员治理策略与审计中心

> 问题：MCP-013  
> 依赖：不阻塞最小只读 MCP 试用  
> 状态：待开始

## 目标

补齐企业治理验收所需的管理策略与审计能力；当前 Token 查询/强制吊销不足以标记「完整治理完成」。

## 范围（方案差距清单）

- 全局 Token 策略
- Tool 启停与风险等级策略
- 用户 / Token / 项目 / Tool 多维审计查询
- 异常调用、失败率、`AGENT_ALL` 高频使用告警
- 限流策略配置与应急暂停
- 审计导出与留存周期

## 分期建议

| 阶段 | 内容 |
|---|---|
| M1 | 审计列表筛选增强 + 导出 |
| M2 | Tool 启停/风险级 + 限流可配置 |
| M3 | 告警与应急暂停 |

## 验收标准

- 与治理方案对齐的能力清单关闭或明确排期豁免。
- 最小只读试用不被本任务阻塞。

## 非目标

- 不作为第一批上线阻断项。
