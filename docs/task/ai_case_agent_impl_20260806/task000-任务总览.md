# task000 - AI 用例生成 Agent 改造任务总览

## 状态

未开始。

## 目标

将【生成用例】从“一次性选择模型并生成结构化草稿”的页面，改造为支持模型选择、后端持久化会话、连续聊天、SSE 流式响应、受控工具调用、草稿编辑校验和人工确认保存的用例生成 Agent。

需求基线：`docs/task/ai_case_agent_20260806/AI用例生成Agent改造方案.md`。

## 交付原则

- 先完成聊天和草稿闭环，再继续企业 Provider、OAuth、Gateway、MCP 扩展。
- 模型输出和文档内容均视为不可信输入。
- 正式用例只能在用户明确确认后创建。
- 会话、消息、文件、草稿、模型和工具调用均绑定项目与用户。
- 每个任务只有在代码、自动化测试和对应验收项均通过后才能标记完成。
- 不允许以编译通过或静态代码存在代替真实链路验收。

## P0 完成定义

必须同时满足：

1. 用户能够新建后端会话并从项目允许范围选择模型。
2. 用户可以多轮聊天，模型能读取历史上下文。
3. AI 回复和工具状态通过 SSE 流式展示。
4. Agent 可以检索已选产品方案并创建、修改、校验草稿。
5. 用户取消后 Provider 流和后续工具实际停止。
6. 未经确认不产生正式用例；确认保存支持逐条部分成功。
7. 不同项目、不同用户和不同权限账号不能越权。
8. 模型、并发、Token、速率和文件容量治理覆盖全部入口。
9. 浏览器、数据库、Redis、文件服务和 Mock Provider 全链路测试通过。

## 非 P0 阻塞项

- 企业 OAuth Provider 授权。
- 企业 Agent Gateway。
- 对外 MCP Server 能力扩展。
- 多 Agent 协作。
- AI 自动执行测试用例。
- 向量数据库；首期允许章节索引加全文检索。
