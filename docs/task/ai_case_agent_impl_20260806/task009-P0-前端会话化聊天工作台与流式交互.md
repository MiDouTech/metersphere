# task009 - P0 - 前端会话化聊天工作台与流式交互

## 状态

进行中。已接入项目模型列表、服务端会话历史、POST-SSE 增量渲染、停止和断流轮询恢复；待补会话列表管理、工具卡片、引用展示和重试交互。

## 目标

将现有三栏【生成用例】页面改造成真正的会话化 Agent 工作台，接入后端会话、项目模型、聊天 SSE、工具状态、执行恢复和草稿变化事件。

## 依赖

- task002 模型接口。
- task003 会话接口。
- task008 Agent SSE API。

## 实现范围

### 1. 左侧会话和资料

- 新建会话。
- 历史会话分页、切换、重命名和删除。
- 来源文档分页、上传、状态、重试和删除。
- 当前会话选中文档管理。
- 项目切换时清理旧项目状态并加载新项目会话。

### 2. 中间聊天区

- 项目可用模型下拉和能力提示。
- 用户消息、AI 消息、失败消息和工具状态卡片。
- content-delta 增量渲染。
- 发送、停止、重试和复制。
- 连接中断、自动重连和执行状态恢复。
- 不展示模型内部推理，只展示平台定义的简短状态。

### 3. 右侧草稿区

- 监听 drafts-changed 刷新或局部合并草稿。
- 草稿筛选、分页、选择和详情。
- 显示校验错误、重复警告和来源引用。
- 保存按钮进入确认预览，不直接让模型保存。

### 4. 状态管理

- 使用按项目、会话隔离的 Store。
- localStorage 只保存当前 conversationId、模型偏好和布局，不保存消息正文。
- 切换会话前处理进行中执行和未保存草稿。
- 同一会话执行中禁止重复发送，或明确支持排队。

### 5. 可访问性与反馈

- 错误码映射为稳定提示。
- 配额、限流、模型不可用和权限不足分别展示。
- 键盘发送和停止操作可用。
- 长消息和大量草稿保持页面性能。

## 验收标准

- 用户可以在页面新建、切换和恢复后端会话。
- AI 自然语言回答流式显示，不再只显示“生成 N 条”。
- 工具调用和草稿变化状态清晰可见。
- 刷新页面或重新登录后恢复消息和执行状态。
- 切换用户不能读取上一用户 localStorage 消息。
- 项目切换后模型、会话、文件和草稿均正确刷新。
- 停止后 UI 与服务端最终状态一致。

## 测试要求

- 前端组件和 Store 单元测试。
- SSE 解析、乱序保护、断线重连测试。
- 项目、会话和模型切换测试。
- 用户切换 localStorage 隔离测试。
- Playwright 浏览器主流程测试。
- 长消息、大量事件和大量草稿性能测试。
