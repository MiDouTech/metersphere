进行中。已补会话隔离、Agent 事件/取消、Provider 回退、PDF/Office、草稿严格参数和逐条事务测试，并通过后端定向测试与前端全量类型检查；待补真实数据库迁移、Provider、浏览器和多节点端到端验收。

## 目标

建立覆盖会话、模型、Agent、工具、草稿、保存、安全和治理的自动化测试体系，并在真实依赖环境完成浏览器闭环验收。

## 依赖

- task001–task012。

## 测试范围

### 1. 单元测试

- 会话上下文窗口和摘要。
- 项目可用模型计算。
- Provider 流事件转换。
- Agent 工具循环和最大轮数。
- 工具参数 Schema、草稿校验和来源引用。
- 错误码、幂等和脱敏。

### 2. 服务和数据库集成测试

- 会话、消息、执行和事件持久化。
- 项目/用户数据隔离。
- Redis 限流和并发准入。
- Token usage 和审计落库。
- 草稿乐观锁。
- 批量保存逐条事务。
- 文件上传、解析和检索。

### 3. SSE 测试

- 正常文本和工具流。
- 首包前错误、首包后断流。
- Last-Event-ID/afterSequence 重连。
- 用户取消、超时和服务重启恢复。
- 多节点或模拟节点切换。

### 4. 权限与安全测试

- READ/GENERATE/UPLOAD/SAVE/CONFIG 全部正反向测试。
- 跨项目、跨用户、个人模型和凭据越权。
- Prompt Injection 和恶意工具参数。
- 敏感信息输入、输出、错误和审计脱敏。
- 文件类型、MIME、病毒样本和容量边界。

### 5. 浏览器 E2E

至少覆盖：

1. 登录并进入【生成用例】。
2. 新建会话。
3. 选择项目允许模型。
4. 上传并等待解析产品方案。
5. 多轮聊天补充需求。
6. Agent 检索资料并生成草稿。
7. 通过聊天修改草稿。
8. 停止或重试一次执行。
9. 刷新页面恢复会话。
10. 确认保存部分草稿。
11. 在【用例】页面查询 `ai_create=true` 的正式用例。

### 6. 真实依赖

- MySQL。
- Redis。
- 实际文件服务/MinIO。
- Mock Provider，用于可重复流、工具调用、超时和错误。
- 至少一个真实模型完成非自动化联调，不将不可重复真实模型作为 CI 唯一依赖。
