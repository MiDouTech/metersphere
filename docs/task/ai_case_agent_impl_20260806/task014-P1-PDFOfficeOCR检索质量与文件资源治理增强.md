# task014 - P1 - PDF/Office/OCR、检索质量与文件资源治理增强

## 状态

未开始。

## 目标

在 P0 文档检索工具基础上，完成各类产品方案真实解析验收、检索质量提升和生产级文件资源治理。

## 依赖

- task006 文档检索工具。
- task013 P0 全链路稳定。

## 实现范围

### 1. 格式验收

- PDF，包括文本 PDF 和扫描 PDF。
- DOC/DOCX。
- XLS/XLSX，多 Sheet 和合并单元格。
- PPT/PPTX，标题、正文和备注。
- PNG/JPG/JPEG OCR。
- TXT/Markdown。

### 2. OCR

- 明确 Tesseract 或其他 OCR 的部署依赖和健康检查。
- 支持语言包配置。
- OCR 失败给出可理解错误。
- 对扫描 PDF 明确 OCR 触发策略。

### 3. 检索质量

- 章节层级和表格内容结构化。
- 中文分词和同义词。
- 关键词检索与可选向量检索的混合排序。
- 片段去重、重排和上下文预算。
- 建立固定评测集和 Recall@K/人工相关性指标。

### 4. 资源治理

- 使用有界线程池和有界队列。
- 解析任务最大重试次数和退避。
- 超时后确保外部 OCR/解析进程可终止。
- 项目并发解析限制和资源监控。
- 原文件、解析结果、索引和事件的生命周期清理。
- 孤儿文件补偿任务。

### 5. 重复文件

- SHA-256 识别重复。
- 评审重复上传是否复用同一物理文件引用，避免重复占用容量。
- 引用计数和删除策略正确。

## 验收标准

- 所列格式均有真实样例解析测试。
- 图片和扫描 PDF 在生产等价环境 OCR 成功。
- 检索评测集达到约定质量指标。
- 大量上传不会导致无界队列和内存持续增长。
- 删除和过期数据最终完成物理清理。
- 重复文件容量统计符合产品定义。

## 测试要求

- 每种格式固定样例测试。
- OCR 环境集成测试。
- 超时、重试、队列满和资源限制测试。
- 检索回归评测。
- 文件清理和重复引用测试。
