# task011 - P2 - 全模块滚动迁移计划

## 状态

未开始

## 目标

在缺陷管理样板验证完成后，按模块逐步迁移用例、接口、测试计划、系统设置等页面，最终形成全系统统一的 UI 权限控制。

## 迁移顺序建议

1. 缺陷管理。
2. 功能用例。
3. 接口测试。
4. 测试计划。
5. 项目管理。
6. 组织设置。
7. 系统设置。
8. 工作台与报表。

## 每个模块迁移步骤

- 梳理页面路由和按钮。
- 定义 `resourceCode`。
- 补充 `permission_resource` 初始化数据。
- 接入路由 `resourceCode`。
- 接入按钮可见/可操作指令。
- 检查后端接口权限。
- 补充权限测试。
- 用四类账号完成验收。

## 不应实现的内容

- 不并行大面积改造未验证模块。
- 不修改与权限无关的业务逻辑。
- 不在样板未验收前推进全量迁移。

## 验收标准

- 每个模块都有资源目录。
- 每个模块都有权限映射表。
- 每个模块至少完成一个无权限账号验收。
- 未迁移模块不受影响。

## 验证要求

- 模块级验收记录。
- 权限回归测试。
- 前端菜单和按钮截图留档。
