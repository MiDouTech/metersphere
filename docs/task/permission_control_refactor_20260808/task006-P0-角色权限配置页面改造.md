# task006 - P0 - 角色权限配置页面改造

## 状态

未开始

## 目标

改造系统、组织、项目角色权限配置页面，支持页面可见、按钮可见、按钮可操作的树形配置。

## 实现范围

- 改造现有用户组/角色权限配置组件。
- 加载后端资源树。
- 展示三态配置：
  - 页面可见
  - 按钮可见
  - 按钮可操作
- 保存时同时提交旧 `permissionIds` 和新 `uiPermissions`。
- 增加管理员角色只读保护。

## 交互规则

- 勾选“可操作”自动勾选“可见”。
- 取消“可见”自动取消“可操作”。
- 子按钮可见时，父页面自动可见。
- 父页面不可见时，所有子按钮不可见且不可操作。
- 内置管理员角色展示“全部权限”，不可取消。
- 配置变更保存前展示差异摘要。

## 不应实现的内容

- 不移除旧权限树。
- 不允许绕过后端校验保存非法资源。
- 不把按钮可见配置直接写入 `user_role_permission`。

## 验收标准

- 项目角色可配置项目级页面和按钮权限。
- 组织角色可配置组织级页面和按钮权限。
- 系统角色可配置系统级页面和按钮权限。
- 保存后重新打开配置页状态一致。
- 管理员角色不可被降权。

## 验证要求

- 勾选联动验证。
- 保存/回显验证。
- 管理员角色只读验证。
- 无权限用户访问配置页拦截验证。
