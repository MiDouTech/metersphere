# task010 - P1 - 后端接口权限一致性与测试补齐

## 状态

未开始

## 目标

保证按钮可操作权限与后端接口权限一致，避免出现“前端允许点击但后端 403”或“前端隐藏但接口可绕过调用”的权限漏洞。

## 实现范围

- 梳理资源目录中 `BUTTON/API` 与 `PermissionConstants` 的映射。
- 对缺陷管理样板补齐缺失权限常量。
- 检查相关 Controller 的 `@RequiresPermissions`。
- 为关键接口补充权限测试。
- 输出权限映射表。

## 检查项

- 每个可操作按钮必须有对应后端权限。
- 每个写操作接口必须有后端权限校验。
- 只控制 UI 可见的按钮必须明确标记不可作为安全边界。
- 多权限 OR 场景需在资源目录中明确说明。

## 不应实现的内容

- 不降低任何已有接口权限。
- 不为了前端方便放宽后端校验。
- 不把 UI 权限表作为后端唯一安全依据。

## 验收标准

- 权限映射表完整覆盖缺陷管理样板按钮。
- 无权限账号直接调用写接口返回 403。
- 有权限账号调用写接口成功。
- 权限测试可在 CI 或本地稳定运行。

## 验证要求

- Controller 权限注解检查。
- 接口权限测试。
- 前后端权限编码一致性检查。
