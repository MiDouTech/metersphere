# task013 - P1 - Agent 安装包管理与平台下载

## 状态

代码已实现并完成后端测试、前端生产构建和安装包产物校验；真实部署环境的上传、MinIO 下载和浏览器端安装闭环仍需部署后验收。

## 目标

安装包不进入 MeterSphere 后端镜像，也不要求每次后端发布时重新构建。系统管理员手动上传独立生成的
Windows Agent ZIP，选择启用版本；内部用户在个人中心点击按钮后直接通过 MeterSphere 下载当前启用包。

## 实现范围

- 新增 Agent 安装包版本表，记录版本、操作系统、架构、文件名、大小、SHA-256、状态和下载次数。
- 使用平台默认文件仓库保存 ZIP，数据库只保存文件定位和元数据。
- 系统管理员可上传、启用、停用、下载和删除安装包。
- 同一操作系统和架构最多启用一个版本，启用新版本会停用旧版本。
- 个人用户只能下载当前启用版本，不能指定未启用包。
- ZIP 上传校验后缀、大小和必要的安装入口，最大 500 MB。
- 保留 `ms.ai.user-agent.bridge.windows-download-url` 作为旧部署兼容后备。

## 发布流程

1. 在 `agent-bridge` 执行 Windows 打包脚本，生成 ZIP、manifest 和 SHA-256 文件。
2. 管理员进入“系统设置 → Agent 集成 → Agent 安装包管理”。
3. 填写版本、选择 Windows/x64、上传 ZIP，并选择是否立即启用。
4. 对比页面 SHA-256 与构建输出，确认一致。
5. 内部用户进入个人 Agent 连接向导，点击“下载安装包”。

## 验收标准

- 未启用包不能通过个人下载接口获取。
- 上传任意 ZIP 或超过限制的文件会被拒绝。
- 启用新版本后，旧版本立即停止作为默认下载包。
- 下载文件大小和 SHA-256 与上传文件一致。
- 删除启用包被拒绝；未启用包删除时同步删除文件仓库对象。
- 安装包发布不触发后端、前端或容器镜像重新构建。

## 当前未验证项

- 真实 MinIO/对象存储上传下载。
- 浏览器登录态下的大文件流式下载。
- 从平台下载后执行 Windows 安装、协议唤起、设备配对完整 E2E。
- 正式 EXE/MSIX 代码签名；当前产物是内部未签名 ZIP。
