# task001 全模块统一刷新入口接入

## 目标

把 `MsModuleRefresh` 从已接入的功能用例、测试计划、缺陷管理扩展到其他一级业务模块，保证每个模块刷新范围明确且不重置用户现场。

## 范围

- 工作台
- 接口测试
- 项目管理
- 系统设置
- 其他有数据拉取的一级业务页

## 实施要点

- 每个页面实现本页 `refresh(context)`，只重拉当前模块所需数据。
- 保持树展开、筛选、分页、排序、滚动位置和已打开详情状态。
- 静态页或无远程数据页可不显示刷新按钮。
- 避免在 `onActivated` 中恢复无条件重拉。

## 验收

- 点击刷新后按钮有 loading，重复点击被阻止。
- 刷新成功展示成功提示和最后刷新时间。
- 至少覆盖工作台、接口测试、项目管理、系统设置中的数据型页面。
- 前端 `npm run type:check` 通过。
