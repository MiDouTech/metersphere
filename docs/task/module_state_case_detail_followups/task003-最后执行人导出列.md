# task003 最后执行人导出列

## 目标

在功能用例导出中增加“最后执行人”列，但不加入导入模板。

## 范围

- 功能用例导出列配置。
- 导出 DTO/字段枚举。
- Excel 导出转换器或用户 ID 到名称解析逻辑。
- 前端导出列选择配置。

## 约束

- `last_execute_user` 不允许人工写入。
- 不修改导入模板。
- 历史空值导出为 `-`。
- 已删除用户按现有用户字段策略显示，不能导致导出失败。

## 验收

- 列表、详情、筛选、导出中的最后执行人一致。
- 修改责任执行人不影响最后执行人。
- 执行结果变更后导出能看到最新最后执行人。
