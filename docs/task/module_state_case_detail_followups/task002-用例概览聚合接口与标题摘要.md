# task002 用例概览聚合接口与标题摘要

## 目标

新增功能用例概览聚合接口，并在详情标题下展示评审摘要、测试计划摘要。

## 接口

建议新增：

```http
GET /functional/case/{caseId}/overview
```

响应包含：

- `reviews[]`：评审 ID、名称、当前用例在该评审中的状态、归档标识、权限跳转信息。
- `testPlans[]`：计划 ID、名称、已执行数、总数、执行率、归档标识、权限跳转信息。
- `personalProgress`：可复用当前个人执行进度结构，避免详情首屏多次请求。

## 实施要点

- 后端批量查询，不允许逐条调用评审/计划详情造成 N+1。
- 评审状态使用当前用例在评审中的状态，不使用整个评审任务总状态。
- 测试计划进度口径为计划内已执行用例数 / 计划内用例总数。
- 已删除关联不展示，已归档展示标识。

## 前端展示

- 每类默认展示最近更新的 2 条。
- 其余以“还有 N 条”展开。
- 有权限时 ID/名称可点击跳转，无权限仅显示文本。

## 验收

- 多评审、多计划用例能正确展示和展开。
- 接口 P95 目标小于 500ms。
- 后端编译通过。
- 前端类型检查通过。
