# task005 评论内嵌分页与局部刷新

## 目标

完善详情内嵌评论区，替代原独立评论 Tab 的完整交互能力。

## 范围

- 默认加载最近 20 条评论。
- 支持“加载更多”或向下滚动分页。
- 发布成功的新评论立即置顶。
- 回复、@用户、附件、删除本人评论保留现有规则。
- 发布、回复、删除后只刷新评论区和评论数量，不重载整个用例详情。

## 兼容

- 原指向评论 Tab 的事件改为打开详情 Tab 并滚动到评论区。
- 继续过滤旧配置中的 `comments` Tab key。

## 验收

- 评论发布后详情中立即可见。
- 分页加载不阻塞详情首屏。
- 权限、通知、附件、回复关系与现有行为一致。
- 删除评论后数量同步更新。
