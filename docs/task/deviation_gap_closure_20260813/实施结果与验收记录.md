## 2. 公开能力边界

- AI 用例 CREATE 为公开且完整的业务能力。
- UPDATE/DEPRECATE 已从公开请求 DTO、响应 DTO 和前端模型移除；数据库列仅作历史迁移兼容，公开编辑链路强制写入 CREATE，发布仍有 CREATE-only 防线。
- Bridge/Runner/MCP/Webhook 属于 PROTOCOL/WEBHOOK 接口，不设置用户前端入口，但均进入接口分类清单并有协议或服务测试。
- WorkBuddy 未有正式适配和验收，因此后端返回不可用，前端不展示，不允许创建连接或调度。
