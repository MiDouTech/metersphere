# task032 - P0 - AI 用例发布后续动作闭环

## 目标

AI 草稿发布成正式用例后，用户无需重新查找用例即可加入测试计划或创建自动化执行任务。

## 实现项

- 从批量发布响应中仅提取成功项的 `formalCaseId`，失败项不得进入后续动作。
- 发布成功弹窗提供“加入测试计划”和“创建执行任务”两个明确入口。
- 测试计划仅显示当前项目未归档计划，关联复用正式后端接口和默认功能用例测试集。
- 创建执行任务将正式用例 ID 载入执行工作台，要求用户补齐模型/Agent、目标地址和环境后再提交。
- 超过 20 条用例时继续执行既有人工确认规则，最终范围由后端按项目权限和用例快照再次校验。
- 写操作按钮与后端权限一致：AI 发布、测试计划关联、AI 执行分别校验对应权限。

## 验收标准

- 部分发布成功时，后续动作只携带成功的正式用例 ID。
- 无测试计划关联权限的用户看不到关联表单和按钮，但发布结果保持成功。
- 无 AI 执行权限的用户看不到创建执行任务按钮。
- 执行工作台能显示已载入数量并创建真实任务，不使用模拟用例或仅前端状态。
- 前端类型检查、路由页签检查、接口闭环清单检查通过。
