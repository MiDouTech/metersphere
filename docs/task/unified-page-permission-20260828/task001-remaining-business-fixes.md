## 边界与失败行为

- 同步按钮只对同时具备用例读取和测试计划关联权限的用户可见，后端再次校验权限与项目所有权。
- 已归档计划不参与项目级同步；同步过程不插入未关联的新用例。
- 切换项目后先清理旧选中状态，再发起新项目请求，避免用旧模块 ID 查询新项目。
