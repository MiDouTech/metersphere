# task008 - P1 - 产品方案上传、存档与异步解析流程

## 状态

部分完成

## 目标

支持用户上传产品方案文件，文件保存到对象存储，数据库记录元数据，并通过异步任务完成解析和状态推送。

## 实现范围

- 新增上传接口：`POST /functional/case/ai/document/upload` 或等效接口。
- 原文件保存至现有 MinIO / 文件服务。
- 数据库保存：
  - 文件 ID。
  - 原始文件名。
  - MIME。
  - 大小。
  - SHA-256。
  - 项目 ID。
  - 会话 ID。
  - 解析状态。
  - 解析结果位置。
  - 错误信息。
- 上传成功后自动触发解析任务。
- 解析过程通过 WebSocket / SSE / 轮询推送状态。

## 状态流

- `UPLOADED`：文件存档完成。
- `PARSING`：文本提取 / OCR 中。
- `PARSED`：可用于生成。
- `GENERATING`：模型生成中。
- `GENERATED`：草稿完成。
- `FAILED`：解析或生成失败。

## 安全要求

- 扩展名与 MIME 双重校验。
- 限制单文件大小、数量及总容量。
- 禁止可执行文件参与自动解析。
- 压缩文件限制解压层级、文件数和解压后总大小。
- 预留病毒扫描接口。

## 验收标准

- 上传文件在对象存储和数据库中均有可追溯记录。
- 上传成功后能看到解析状态变化。
- 解析失败有明确错误原因和重试入口。
- 文件删除、下载、重新解析均记录审计。

## 验证要求

- 文件上传接口测试。
- 文件类型校验测试。
- 文件大小限制测试。
- 异步状态流测试。
- 解析失败重试测试。
