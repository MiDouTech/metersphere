# task005 - P0 - 草稿管理、编辑、删除、重新生成与状态管理

## 状态

部分完成

## 目标

实现 AI 生成草稿的完整管理能力，支持分页查询、编辑、删除、重新生成、状态筛选、重复提示和草稿自动保存。

## 实现范围

- 新增草稿分页接口。
- 新增单条草稿详情接口。
- 新增草稿更新接口。
- 新增草稿删除接口。
- 新增草稿重新生成接口。
- 支持草稿状态：
  - `DRAFT`
  - `VALIDATING`
  - `INVALID`
  - `READY`
  - `SAVING`
  - `SAVED`
  - `FAILED`
- 支持草稿校验结果展示。
- 支持重复用例提示：
  - 按项目维度。
  - 按名称。
  - 按步骤内容。
  - 生成指纹。
- 支持乐观锁，防止多窗口编辑覆盖。

## 前端要求

- 草稿列表支持筛选、勾选、全选。
- 详情编辑区字段与手工新建功能用例一致。
- 修改草稿后自动保存。
- 自动保存失败时必须提示。
- 删除草稿不影响正式用例。

## 验收标准

- 草稿可分页查询。
- 草稿可编辑并保留最新版本。
- 多窗口修改冲突能被识别。
- 重复用例有明确提示，但不强制阻断用户确认。
- 草稿删除后不影响正式用例。

## 验证要求

- 草稿 CRUD 接口测试。
- 乐观锁冲突测试。
- 重复检测测试。
- 前端自动保存测试。

## 执行记录

- 已在草稿表补充软删除、校验提示、重复指纹、重复标记字段。
- 已实现项目 + 当前用户维度的数据隔离查询。
