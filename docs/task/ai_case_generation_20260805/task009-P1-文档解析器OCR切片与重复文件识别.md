# task009 - P1 - 文档解析器、OCR、切片与重复文件识别

## 状态

部分完成

## 目标

实现产品方案文件的内容解析能力，将可识别文件转换为可供 AI 生成用例使用的结构化文本、章节索引和引用片段。

## 支持范围

首期自动解析范围：

- PDF
- DOC / DOCX
- XLS / XLSX
- PPT / PPTX
- TXT
- MD
- HTML
- JSON
- XML
- YAML
- 常见图片格式

不支持自动解析的文件允许存档，但不得宣称已自动解析。

## 实现范围

- 文档文本提取。
- 图片 OCR。
- 文档章节识别。
- 文本切片。
- 摘要生成。
- 解析结果保存到对象存储。
- 数据库保存摘要、章节索引、解析器类型和错误信息。
- 使用 SHA-256 做重复文件识别。
- 大文件解析超时、重试和资源配额控制。

## 验收标准

- 支持范围内的文件可提取文本。
- 图片类文件可通过 OCR 得到文本内容。
- 大文件不会阻塞同步请求。
- 重复上传相同文件时能识别 SHA-256。
- 无法解析的文件只标记为存档，不标记为已解析。

## 验证要求

- 多格式样例解析测试。
- OCR 测试。
- 大文件超时测试。
- 重复文件识别测试。
- 不支持格式存档测试。

## 执行记录

- 已新增基础解析服务 `AiSourceDocumentParserService`。
- 已支持文本类文件自动解析：
  - TXT
  - MD
  - HTML / HTM
  - JSON
  - XML
  - YAML / YML
  - `text/*` MIME 类型
- 已实现基础 HTML 标签剥离。
- 已实现文本切片，默认每片约 1800 字符，并生成章节索引 JSON。
- 已生成解析摘要，保存到 `ai_source_document.summary`。
- 已将解析结果 JSON 存入现有文件服务，并把返回文件 ID 保存到 `parsed_result_path`。
- 已使用 SHA-256 做同项目同用户重复文件识别；若历史文档已解析，则新文档标记重复并复用历史解析结果。
- 对 PDF、Office、图片等未接入解析器/OCR 的文件，已明确标记失败原因，不会标记为已解析。
