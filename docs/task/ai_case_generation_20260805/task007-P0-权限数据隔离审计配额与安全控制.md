# task007 - P0 - 权限、数据隔离、审计、配额与安全控制

## 状态

部分完成

## 目标

补齐 AI 生成用例功能的权限、数据隔离、凭据安全、内容安全、审计和成本控制，防止越权访问、敏感信息泄露和模型滥用。

## 实现范围

- 权限点：
  - `READ`
  - `GENERATE`
  - `UPLOAD`
  - `SAVE`
  - `CONFIG`
- 首期可映射现有功能用例权限，但必须保留扩展点。
- 所有查询和操作校验 `project_id` 与当前用户项目成员关系。
- 系统模型与个人模型连接区分授权范围。
- 前端不回显完整 API Key、OAuth Token 或其他凭据。
- 日志和异常信息脱敏。
- 上传、解析、生成、编辑、删除、保存、授权、连接测试均记录审计。
- 配额控制：
  - 项目级模型白名单。
  - 并发限制。
  - Token 配额。
  - 单任务生成用例数量上限。

## 内容安全

- Prompt 注入防护。
- 敏感信息脱敏。
- 模型输出字段白名单。
- 禁止模型输出驱动权限字段或系统字段。

## 验收标准

- 无权限用户无法访问页面、接口、草稿和来源文件。
- 不同项目和用户之间的文件、会话、草稿和凭据不可越权访问。
- 凭据不在前端、日志、异常中明文出现。
- 超出配额时有明确提示。
- 所有关键操作均有审计记录。

## 验证要求

- 权限测试。
- 越权访问测试。
- 日志脱敏测试。
- 配额限制测试。
- 审计记录测试。

## 执行记录

- 已新增 AI 用例权限常量扩展点：
  - `FUNCTIONAL_CASE_AI_GENERATE`
  - `FUNCTIONAL_CASE_AI_UPLOAD`
  - `FUNCTIONAL_CASE_AI_SAVE`
  - `FUNCTIONAL_CASE_AI_CONFIG`
- 首期已映射到现有功能用例权限：
  - 生成/保存映射 `FUNCTIONAL_CASE:READ+ADD`
  - 上传映射 `FUNCTIONAL_CASE:READ+IMPORT`
  - 配置映射 `FUNCTIONAL_CASE:READ+UPDATE`
- 新增接口已通过 `@RequiresPermissions` 和 `@CheckOwner(project)` 做权限与项目成员校验。
- 草稿查询、详情、更新、删除、保存均校验 `project_id + current_user`，避免跨用户读取草稿。
- AI 生成提示词已限制模型不得输出项目 ID、用户 ID、权限字段、Token、密钥、Cookie 等敏感字段。
- 单次生成数量已做默认 50、最大 100 限制。
- 关键操作已记录服务端日志审计：生成、生成失败、编辑草稿、删除草稿、批量保存。
