# task003 P1 测试资产导航顺序与权限资源排序

## 目标

将“用例资产、测试数据、测试环境”整体移动到“业务文档”之后，并保证前端静态路由、后端权限资源排序和不同账号看到的顺序一致。

## 改造范围

- 调整测试资产菜单与子路由声明顺序。
- 更新对应权限资源 `pos` 数据迁移，避免只改前端导致服务端菜单仍按旧顺序返回。
- 保持菜单 key、路由 name、权限 ID 和收藏/最近访问兼容，不通过删除重建改变权限绑定。
- 校验管理员、普通用户、仅部分菜单权限用户的排序。

## 验证与完成标准

- 目标顺序在刷新、重新登录和不同权限账号下保持一致。
- 原 URL、菜单权限和面包屑不变。
- 数据迁移可重复执行且不会不断递增或打乱其他菜单 `pos`。
- 对前后端菜单排序分别补充测试。
