# task015 P1 旧流程、默认项目与 MCP 独立入口下线

## 依赖

task002、task005、task007、task008、task013、task014 全部验收；需完成兼容观察和回滚演练。

## 目标

在新流程、新资产导入和 Agent 页面稳定后，隐藏会形成第二配置源或旧产品概念的入口，并按版本计划收口兼容接口和死代码。

## 下线清单

- 隐藏“项目管理 / 模板管理 / 缺陷模板 / 工作流设置”，旧页面只读期结束后不再可写。
- 停止项目级 BUG 工作流写接口；保留期内返回“已迁移至权限控制”及目标入口，期满移除。
- 移除“从默认项目导入”前端入口和文案；旧接口按兼容版本计划转发或下线。
- 删除 Agent 集成中的独立 MCP 技能包模块，保留 Token Tab 内说明和下载。
- 清理不再引用的抽屉、旧选择器、旧路由和重复状态选项代码，但不删除仍承担历史数据读取的服务。

## 上线门禁

- 全局流程迁移异常已处理或有明确隔离方案，所有缺陷状态写入口通过 task008 清单验收。
- 新资产导入血缘完整，项目用例及调度规则新链路稳定，无规则保存资产 ID。
- 埋点/日志证明观察期内旧入口调用量达到下线阈值；API 消费方已通知并完成版本迁移。
- 已验证功能开关或版本回退方案；回退不能重新开放双写造成配置分叉。

## 验证与完成标准

- UI、路由、权限资源、国际化和帮助文档中不再暴露旧入口或旧文案。
- 直接调用旧写接口不能创建第二套流程配置。
- 数据归档而非直接物理删除；任何物理清理另立任务并经备份验证。
- 完成全链路回归、升级回归、旧客户端兼容检查和下线记录。
