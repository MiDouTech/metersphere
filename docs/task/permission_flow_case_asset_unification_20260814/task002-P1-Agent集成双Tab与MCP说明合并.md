# task002 P1 Agent 集成双 Tab 与 MCP 说明合并

## 目标

Agent 集成页只保留“我的 Agent Token”和“我的 AI Agent”两个 Tab，将 MCP 技能包说明移动到 Token 搜索框上方，删除独立 MCP 技能包模块入口但保留下载能力。

## 改造范围

- 页面顶层改为两个可路由或可恢复状态的 Tab。
- Token Tab 顺序固定为：MCP 说明与下载 → 搜索/操作区 → Token 列表。
- AI Agent Tab 承载当前“我的 AI Agent”全部功能。
- 移除独立 MCP 技能包卡片、菜单或重复说明，复用现有组件和接口。
- Tab 切换不丢失搜索条件；刷新后恢复当前 Tab，非法 Tab 回到 Token。

## 后端与权限

- 不改变 Token 和 Agent 现有业务接口。
- MCP 包下载接口继续执行原权限和版本校验，不因入口移动而匿名开放。
- 两个 Tab 分别按现有权限显示；无任一权限时按统一 403 页面处理。

## 验证与完成标准

- 页面仅出现两个 Tab，不再有第三个“MCP 技能包”模块。
- MCP 说明位于 Token 搜索框上方，下载链路可用。
- Token 新建、删除、复制、搜索及 AI Agent 操作回归通过。
- 桌面常用分辨率和窄屏无溢出，国际化文案完整。
