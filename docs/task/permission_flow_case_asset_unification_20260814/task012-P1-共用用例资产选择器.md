# task012 P1 共用用例资产选择器

## 依赖

task010；引用信息展示可在 task011 完成后增强。

## 目标

提供项目用例导入和 Agent 调度规则共同使用的用例资产选择器，统一目录、搜索、分页、多选、权限和已删除资产过滤。

## 组件契约

- 输入：目标项目 ID、选择模式、已选项目用例/资产 ID、最大选择数、业务场景。
- 输出：选中的资产用例 ID 集合及最小展示摘要；组件本身不直接写调度规则。
- 左侧目录、右侧资产列表；支持 ID/名称搜索、分页、多选、全选当前页和取消选择。
- 跨页选择稳定，已选区可移除；禁止因翻页丢失选择或重复提交。
- 已删除、无权限、跨组织资产不展示；后端提交时仍需再次校验。

## 复用边界

- 选择器负责“选择资产”，导入服务负责“创建项目副本和血缘”。
- 项目用例场景选择后进入导入确认；调度规则场景选择后执行导入并用返回的项目用例 ID 更新规则表单。
- 不在组件中复制两套导入逻辑或根据页面来源改变权限规则。

## 验证与完成标准

- 两个业务入口使用同一组件和相同查询接口。
- 搜索、分页、跨页多选、重复选择、空结果、权限变化和资产删除回归通过。
- 组件返回稳定 ID，不以名称匹配用例。
- 具备组件测试及两个宿主页的集成测试。
