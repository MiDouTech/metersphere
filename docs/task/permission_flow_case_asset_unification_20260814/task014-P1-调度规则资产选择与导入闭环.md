# task014 P1 调度规则资产选择与导入闭环

## 依赖

task012、task013。

## 目标

在 Agent / 调度队列 / 调度规则 / 新建规则中，为“用例 ID”提供从用例资产选择能力；保存规则前将资产导入当前项目，规则只保存项目用例 ID。

## 交互流程

- “用例 ID”区域提供“从用例资产导入”按钮并打开共用选择器；保留已有合法项目用例选择方式时须明确区分来源。
- 选择资产后先显示待导入摘要，不把资产 ID 冒充项目用例 ID。
- 保存规则执行两阶段流程：先导入当前项目并取得项目用例 ID，再提交规则。
- 导入成功而规则保存失败时，保留已导入副本并提示用户可重试规则保存；不得重复导入。
- 规则保存成功后表单及详情展示项目用例信息，并可追溯资产来源。

## 后端

- 调度规则接口只接受并验证当前项目的项目用例 ID，拒绝资产源 ID、跨项目 ID、无权限或已删除项目用例。
- 可提供编排接口统一执行导入和规则保存，或由前端按幂等导入令牌串联；无论采用哪种方式，都必须定义部分成功恢复策略。
- 执行器保持使用项目用例 ID，以复用项目环境、模板、权限和执行模型。

## 验证与完成标准

- 从资产选择到规则保存、调度执行形成完整链路，数据库规则字段中不存在资产源 ID。
- 多选、重复资产、导入失败、规则保存失败、重试、跨项目和权限失效场景有测试。
- 已存在对应项目副本时按既定冲突策略复用或复制，结果可预期且不产生重复血缘。
- 用户无需手工粘贴用例 ID。
