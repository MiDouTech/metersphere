# task013 P0 项目用例从用例资产导入

## 依赖

task011、task012。

## 目标

将“测试用例 / 用例 / 执行用例”下的“从默认项目导入”改为“从用例资产导入”，后端从资产库创建当前项目的独立用例副本并写入血缘。

## 业务流程

```text
打开共用资产选择器
→ 选择资产用例
→ 确认目标项目、模块及冲突策略
→ 异步导入/复制为项目用例
→ 写资产到项目副本血缘
→ 返回成功、失败和目标项目用例 ID
```

## 后端

- 新接口以资产用例 ID 为来源，以当前项目和目标模块为落点；校验来源与目标的组织、权限和删除状态。
- 复用现有异步导入进度、字段映射、附件复制和冲突处理，但不再读取隐藏默认 Hub 项目。
- 每项结果明确返回资产 ID、项目用例 ID、处理状态和失败原因，支持幂等请求键防止重复点击产生重复副本。
- 导入成功与血缘写入必须一致；失败可补偿，不能生成无法追踪的项目副本。

## 前端与兼容

- 所有文案改为“从用例资产导入”，打开 task012 选择器。
- 导入完成后刷新当前模块列表并可定位成功用例，部分失败展示可下载明细。
- 旧默认项目导入接口保留一个兼容版本，内部转发可确定的资产来源；新前端不得调用。

## 验证与完成标准

- 导入结果是当前项目用例 ID，源资产修改不会隐式覆盖项目副本。
- 重复提交、部分失败、附件/步骤/自定义字段、无权限和软删除资产均有测试。
- 新导入全部存在可靠血缘，旧“默认项目”文案和新页面调用清零。
