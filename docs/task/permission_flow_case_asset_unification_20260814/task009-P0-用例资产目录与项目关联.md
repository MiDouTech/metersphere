# task009 P0 用例资产目录与项目自动关联

## 目标

建立独立于业务项目的用例资产目录，并在真实项目创建时于同组织自动创建或复用同名目录；目录可关联多个同名业务项目。

## 数据模型

- 新增 `case_asset_catalog`：ID、组织 ID、名称、规范化名称、来源、是否人工改名、创建/更新/删除信息。
- 新增 `case_asset_catalog_project_rel`：目录 ID、项目 ID、关系类型和创建信息。
- 同组织规范化名称建立有效数据唯一约束；不同组织严格隔离。
- 运行时只以关系表关联，不以名称作为外键。

## 项目生命周期

- 项目创建后通过现有资源扩展点或可靠事件执行幂等 upsert：同组织无目录则创建，有则复用并写关系。
- 同步失败可重试和补偿，不留下重复目录；是否阻断项目创建按现有事务边界实现，默认不阻断核心项目创建。
- 项目删除只解除关系，不删除目录和资产用例。
- 项目改名前查询关联目录；存在关联时二次确认文案必须包含目录名：`该项目已关联测试资产：{目录名称}，是否确认改名`。
- 用户取消不修改任何名称；确认后，仅“目录只关联该项目且从未人工改名”时同步目录名，否则只改项目名。

## 页面与接口

- 左侧目录支持新建、搜索、分页/虚拟滚动；产品按钮可叫“新建用例项目”，帮助文案明确不会创建业务项目。
- 名称加粗紫色，ID 小一号灰色。
- 目录 CRUD 接口执行组织隔离、规范化重名校验和软删除/引用规则。

## 验证与完成标准

- 同组织大小写、空格等规范化同名目录合并；跨组织不合并。
- 并发创建同名项目不产生重复目录或关系。
- 手工新建目录不创建业务项目。
- 项目改名二次确认及三种目录同步分支全部通过测试。
- 提供历史项目补建目录的幂等任务和统计报告。
