# task010 P0 资产用例 CRUD、导入与详情

## 依赖

task009。

## 目标

把“用例资产”从跨项目只读聚合页升级为可维护资产库：选中目录后可新建、导入、查看、编辑、保存和软删除资产用例。

## 后端

- 新增资产用例分页、详情、新建、更新、软删除和导入接口，以 `catalogId` 为归属，不再要求真实 `projectId`。
- 复用功能用例字段校验、步骤、附件、自定义字段和异步导入能力，但明确资产用例没有业务项目执行上下文。
- 导入任务记录目标目录、操作者、文件、总数、成功/失败明细及冲突策略。
- 软删除后详情按权限提供已删除提示；已有项目副本及历史计划不变，所有新导入入口拒绝该资产。
- 资产权限独立建模，所有查询按组织和目录权限过滤。

## 前端

- 右侧列表提供新建、导入、搜索、分页、删除；删除状态列。
- 点击用例 ID 或名称进入资产专用详情路由，支持编辑、保存和返回原目录/筛选状态。
- 详情组件可复用项目功能用例编辑能力，但移除项目执行、状态等不适用字段和操作。
- 删除前提示对项目副本与历史计划无影响、删除后不能再次导入。

## 验证与完成标准

- 单条新建和文件导入均写入选中目录，不创建业务项目。
- ID/名称跳转、刷新、编辑、附件、自定义字段和返回定位可用。
- 跨组织、无权限目录、已删除目录/资产请求均被后端拒绝。
- 删除资产后项目副本和历史计划可正常查看，资产选择器不再返回该资产。
- 大文件、部分失败、重复数据和导入重试有测试与清晰结果。
