# task005 P0 项目缺陷工作流迁移预检与迁移工具

## 依赖

task004。

## 目标

盘点现有项目级 BUG 工作流差异，生成可审阅的全局流程草稿和映射报告；支持存量缺陷按原版本回填及管理员显式迁移，不静默覆盖差异。

## 实现范围

- 预检统计各项目状态、初始/结束状态、流转、角色授权、使用中状态和异常引用。
- 使用稳定编码而非名称直接建立状态映射；同名不同义、同码不同定义列为冲突。
- 生成全局流程草稿和项目差异报告，发布前由管理员确认。
- 为存量本地缺陷回填可追溯的 `workflow_id/workflow_version` 和状态映射；无法确定的记录进入迁移异常表，不自动猜测。
- 历史缺陷版本迁移必须先生成逐状态影响预览，管理员确认后异步执行；未映射状态阻断该批次。
- 工具支持 dry-run、幂等重跑、批次状态、失败明细、断点续跑和结果导出。

## 安全与兼容

- dry-run 不修改业务数据；正式任务记录执行人、参数、前后版本、映射和数量。
- 迁移期间新建缺陷只能绑定已发布全局版本，不写回旧项目工作流。
- 旧工作流写接口切换为只读提示，但最终隐藏由 task015 执行。
- 提供按迁移批次回滚绑定关系的方案；已发生后续状态流转的记录不得机械回滚。

## 验证与完成标准

- 对相同流程、存在差异、孤立状态、未知状态和大量数据分别验证预检结果。
- 预览数、成功数、跳过数、失败数与数据库核对一致。
- 重跑不会重复创建流程、映射或迁移历史。
- 未经显式确认不改变任何存量缺陷；异常记录可定位和人工处理。
