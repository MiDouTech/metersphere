## P2 CR-07 列表统计无界加载全部资产行并逐系统查询模块

位置CaseAssetSystemService.java list()第140至159行（以送审当前文件为准）。统计查询SELECT system_id,system_module_id将当前组织资产子树全部有效用例加载为Map列表，随后在Java聚合；每个系统又执行一次模块查询。每次打开和分类后刷新均走此路径。

影响：目录摘要响应只需要计数及目录，但数据库返回行数和应用内存随全部资产数增长；模块查询次数随系统数增长。无分页或上限，不能因页面用例列表分页20条而视为已限制。此为静态可确认的无界读取/N+1，不冒称已压测出超时。

建议：数据库按system_id/system_module_id分组计数，模块按当前组织一次批量读取再分组；保留Hub、有效目录及组织过滤。补验多系统/模块/未分类数量和SQL查询次数，证明不会读取每条用例实体。按现行评审规则P2默认修复；延期需用户明确接受风险，不以作者测试通过自动豁免。
