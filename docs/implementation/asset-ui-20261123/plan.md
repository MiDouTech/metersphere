## 接口决策与安全边界
保留 kind=SECRET；新增可选 secretType。有 secretType 时 value 必须是包含 fields 名称/值数组的 JSON，账号密码类要求 username 和 password；其他类最少一行，最多20行，名称不重复且1–64字符，值非空且最多100000字符。字段名称也包含在密文中，不向列表或历史返回。
无 secretType 的旧调用保持原字符串协议，元信息显示 OTHER。新增可选 keepSecret：仅编辑已有 SECRET 时允许，服务端按项目和乐观版本锁读取旧内容，不接收明文回填；前端默认保留，选择替换后填写整组字段。
执行器授权解析保留 value 字符串并附加 secretType，结构化 value 是 JSON；运行会话仍固定原版本。所有失败复用安全错误结构与脱敏诊断。
