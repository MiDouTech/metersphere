- 新迁移：`V3.7.2_98__quality_step_facts.sql`、`V3.7.2_99__quality_finalization.sql`、`V3.7.2_100__quality_policy_trial.sql`。历史摘要不回填，旧结果不重新判定通过。

- Runner `MS_RUNNER_STATE_DIR` 与持久卷 `/runner/state`；敏感 journal 使用 `MS_RUNNER_STATE_KEY`（Base64 32 字节）。结束租约后 journal 清理需运维管理，尚无自动保留期。
