# MeterSphere 权限控制补强修复方案 V1.3

> 日期：2026-08-14  
> 本文补充 V1.0、V1.1、V1.2；发生冲突时以本文为准。

## 1. 修复目标

1. 权限、角色状态和成员关系变更在事务提交后立即影响在线会话。
2. UI 资源权限必须有真实业务落点，禁止只登记资源、不接入页面。
3. 新旧权限写接口共用范围、依赖、管理员保护和资源合法性校验。
4. 角色成员分页、搜索、并发去重和系统/组织/项目范围归属形成闭环。
5. 只读用户、管理员角色、UI 可操作与关联接口权限的行为保持一致。
6. 权限变更可审计、未知编码可观测，并由自动化测试阻止再次偏差。

## 2. 强制实现规则

### 2.1 在线权限

- 角色权限、UI 权限、启停、删除、成员添加或移除成功提交后，刷新受影响用户的 Redis Session 权限快照；刷新失败时删除对应会话，按失败关闭处理。
- 会话刷新只能在事务提交后执行，事务回滚不得改变在线权限。
- 前端重新获取登录用户后重建菜单、路由、页签和按钮权限。

### 2.2 权限写入

- 原子保存接口和兼容写接口必须使用同一策略校验。
- 权限编码必须属于角色类型；UI 资源必须存在、启用并属于角色范围。
- 写权限自动补齐查询权限；按钮可操作自动要求可见及关联接口权限。
- 管理员角色的修改、删除、禁用和成员变更始终由后端拒绝。

### 2.3 UI 资源落地

- PAGE 绑定路由资源码，TAB 绑定页签可见性，BUTTON 绑定可见/可操作指令。
- 已有关联接口权限的旧 `v-permission` 控件纳入 UI 权限兼容收口，不能绕过角色 UI 配置。
- 增加静态覆盖检查：启用的叶子资源必须有显式资源码落点，或有可验证的关联接口权限兼容落点。

### 2.4 成员关系

- 系统角色使用 `sourceId=system`；组织角色使用组织 ID；项目角色使用项目 ID。
- 成员列表在角色校验完成后再启动 PageHelper，启动后的第一条 SQL 必须是成员列表查询。
- 数据库增加 `(user_id, role_id, source_id)` 唯一约束，批量添加按幂等语义处理。
- “旧用户组角色迁移”限定为原系统级全局非管理员角色；组织、项目成员关系保留其作用域，禁止把局部成员提升为拥有全局管理员等价权限的系统成员。

### 2.5 前端只读与依赖

- 管理员角色或当前用户缺少 UPDATE 权限时，角色抽屉为只读，显示“查看”，隐藏保存区。
- 勾选按钮可操作时自动开启关联接口权限；关闭接口权限时同步关闭相关按钮可操作权限。
- 系统、组织、项目角色均提供成员入口；非系统角色必须先选择具体组织或项目。

## 3. 实施结果

| 补强项 | 前端 | 后端/数据库 | 结果 |
|---|---|---|---|
| 在线权限即时生效 | 登录态重新获取后按新权限重建菜单/路由 | 事务提交后刷新受影响用户 Redis Session，失败则删除会话 | 已闭环 |
| 管理员保护与只读 | 管理员及无 UPDATE 权限用户仅可查看 | 原子保存、兼容保存、启停、删除、成员变更均执行后端保护 | 已闭环 |
| 权限依赖 | 操作按钮自动开启关联数据权限，关闭读权限同步关闭写权限 | 写权限补读权限；可操作资源补关联接口权限；同接口兼容按钮作为能力组统一 | 已闭环 |
| UI 资源落点 | 路由、通用页签组件、按钮指令均接入资源控制 | 会话下发资源码、关联按钮权限和受管路由集合 | 已闭环 |
| 资源目录偏差 | 已取消的项目/系统用例视图和不存在的占位入口不再展示 | V57 停用占位资源并校正真实路由；静态检查覆盖 114 个启用资源 | 已闭环 |
| 角色成员 | 系统、组织、项目角色均有成员入口和只读态 | 作用域校验、真实分页、成员合法性校验、唯一键及幂等批量写入 | 已闭环 |
| 角色与流程操作 | 角色保存/删除/启停/成员；流程及流程角色增改删启停均有入口 | 对应接口完整，删除流程/角色时同步清理授权关联 | 已闭环 |
| 权限中文化 | 类型、范围、接口权限使用中文；未知码显示明确占位 | 未知码去重上报并记录操作者 | 已闭环 |
| 用户组收口 | 移除系统、组织、项目用户组菜单入口，仅保留权限控制 | 旧接口仅作为兼容入口并复用统一校验，不再作为新产品入口 | 已闭环 |
| 审计 | 写操作均从真实 UI 入口触发 | 角色保存、权限、启停、删除、成员增删写入操作日志 | 已闭环 |

## 4. 自检结论

- 未发现本需求范围内“只有前端、没有后端逻辑”的功能：角色、成员、权限资源、流程操作均有后端接口和数据落点。
- 未发现本需求范围内“只有后端、没有前端入口”的产品功能：角色与流程 CRUD、权限与成员维护均有入口。旧用户组兼容接口保留是升级兼容策略，不作为产品功能入口。
- 已停用无法对应当前页面结构的资源项，避免出现后台可勾选但运行时无效果。
- 关联同一接口权限、且仍使用旧权限指令的按钮按一个能力组同步配置，后端拒绝矛盾状态，避免前后端语义不同。
