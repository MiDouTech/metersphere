# 完整预检内部错误分析与恢复方案

## 已确认原因与证据

TC12 V3独立可执行性检查为READY，原内容解码问题不再是当前直接阻塞。完整预检在有/无测试计划时均失败；本轮进一步以网页登录态调用同一REST预检，仍HTTP 500，traceId=0d2a7c34-a081-4c98-89d6-6ec9ead07aa0。因此仅切换MCP/网页登录态不能解决。

发现明确的前置配置错误：执行档案1698711826730999808的environmentId为mido-order-20261019。环境资产目录返回total=1，只有默认Mock环境1698710040024604673，没有该引用；指定读取返回400 BUSINESS_ERROR。

该environmentId由本助手在10月19日创建档案时填写为自定义标识，没有先建立真实环境资产。这是本次测试前置配置错误，不是用户用例内容问题。平台创建时允许保存无效引用，也属于需要补强的参数/业务校验。

证据：output/playwright/msp-quality-20261020/environment-diagnosis.log、preflight-rest-diagnostic.log。

## 为什么前面通过，后面失败

执行档案与环境资产是两个对象。早期ENVIRONMENT检查验证档案启用、URL及允许域名；后续ADDITIONAL_ASSETS将档案environmentId追加为ENVIRONMENT资产引用，要求资产存在、属于项目且有已发布版本。

所以“档案启用/URL正确”不能代表“环境资产存在且已发布”。当前配置在后者不成立。

## 为什么返回500而不是清楚的阻塞项

源码中AgentExecutionPreflightService.preflight为事务方法；TestAssetCatalogService类标注@Transactional(readOnly=true)，默认加入已有事务。resolveContext遇到资产不存在时抛MSException（RuntimeException），外层预检捕获它并试图保存BLOCKED。

按此事务结构，内层异常可能已将共享事务标记rollback-only；外层捕获不能撤销标记，最终提交可能抛UnexpectedRollbackException，再经AgentSafeErrorMapper映射为AI_EXECUTION_INTERNAL_ERROR。此外非稳定编码的业务异常也会被该映射器转为同一错误。

该事务路径是有代码依据的高可能解释，尚未取得远端堆栈，不能写成已确认线上实际抛出的异常。需按上面的REST trace以及原MCP trace a44163be-7bbd-4a02-9407-48c32d817511、aa4a4fb3-7819-4498-9065-76c0558963e3核实。

## 最小恢复方案：先纠正配置，不关闭检查

1. 在本项目创建真实米多星球测试环境资产，配置目标测试地址和必要参数，取得平台生成的ID。不要使用默认Mock环境冒充真实环境。
2. 发布该环境资产，回读发布版本及内容。
3. 更新原执行档案environmentId为真实资产ID，保留baseUrl、allowedOrigins、runnerType等正确配置。按接口要求携带当前版本，避免覆盖其他修改。
4. 使用新的请求重新预检；确认ADDITIONAL_ASSETS通过且整体PASSED，取得新的preflightId。
5. 正常创建任务、领取租约，再执行真实步骤与门禁正反向测试。

这是补齐必要前置条件，不是绕过门禁。当前尚未执行配置修正，所以不能保证修正后没有其他阻塞；须以实际预检结果判断。

## 代码修复方案

- 环境档案创建/更新时验证environmentId存在、属于项目，并拒绝无效引用；未发布可允许保存草稿，但执行预检必须明确提示发布。
- 将“执行档案检查”和“环境资产检查”在预检中分别展示，使用稳定错误码ENVIRONMENT_ASSET_NOT_FOUND/ENVIRONMENT_ASSET_NOT_PUBLISHED/ENVIRONMENT_ASSET_PROJECT_MISMATCH等，名称接入现有错误体系。
- 将预期配置缺失表示为结构化检查结果，避免在参与同一事务的只读服务中抛异常后又尝试继续提交。可拆分只读评估与短事务保存预检记录；若使用独立事务保存诊断，须明确快照一致性及审计边界。
- 不采用全局noRollbackFor(Exception)或吞所有异常的方式；真实SQL/解码异常仍要记录日志并返回安全系统错误。
- 错误响应应保持HTTP状态和业务封装语义一致。此次HTTP 500/400外层code仍为100200，而data内是错误对象，客户端须识别，服务端应统一协议。

验收：无效环境引用应在保存或预检中明确指出；未发布资产应明确阻塞；真实已发布环境能正常冻结；这些预期失败不再变成500；跨项目引用拒绝；数据库真实异常有trace而不泄露SQL；新任务完整证据放行、各负向规则拒绝并回读计划。
