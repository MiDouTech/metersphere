## 已发现的交互问题与建议

### UX01：资产导入操作按钮不常驻（建议优先级P2）

复现：列表→导入→从用例资产导入。1738×826视口，弹窗底724.74px，取消及导入按钮初始top1251.97px，首次不可见；body高度620px、scrollHeight1203px、overflow:auto。键盘导航到取消按钮可使底部滚动，截图09确认按钮可见，取消成功，因此不是完全不可达。截图02为首次打开、09为滚动后。

影响：目录较多/较矮窗口下不易发现提交按钮，Tab标题也随内容滚出视野。

建议：`importFromDefaultModal.vue`将底部操作移动到a-modal的footer插槽，正文限高并滚动；目录与列表区域独立滚动；Tab区置于非滚动头部。保留disabled/loading及原导入服务，不改业务提交协议。验收至少覆盖1366×768、1738×826和200%缩放：取消/导入始终可见，正文无覆盖。

### UX02：导入切换实际为两个弹窗切换（建议优先级P3）

Excel窗口与980px资产窗口分属两个a-modal。Tab切换期间旧弹窗退场、新弹窗入场，短暂同时存在两个可见modal，尺寸和标题也改变；稳定后只剩一个，双向切换成功。脚本严格单modal定位曾在动画期命中两个，不将该瞬时脚本错误当持久在线业务失败。

建议：拆出Excel与资产的表单内容，改由同一个a-modal承载双Tab，保留各自校验、任务状态、footer及提交锁；提交中禁止切换。须明确未提交文件切换后的保留/清理行为；当前复用原关闭清理逻辑，不承诺保留文件。验收连续往返10次、异步加载/提交期间切换不会双弹窗、残留遮罩、重复请求或丢失服务端任务。
