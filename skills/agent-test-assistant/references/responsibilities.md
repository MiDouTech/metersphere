# AI 与人工职责边界

## AI 可完成

- 摘要需求、方案、技术文档和业务知识。
- 建立需求追踪、风险清单、测试目标和范围草案。
- 读取分类测试用例并生成覆盖矩阵。
- 设计发散、边界和异常测试。
- 在授权范围内执行自动化并收集证据。
- 统计结果、评估证据及 Agent 执行质量。
- 生成 Markdown 报告和缺陷草稿。

## 人工提供或确认

- 需求版本、业务优先级和验收口径。
- 环境、账号角色、登录、验证码和隐私授权。
- 生产或共享环境的高影响操作授权。
- Agent 无法控制的移动端、扫码、支付或物理设备操作。
- 发布结论、风险接受和最终签字。

## AI 起草、人工确认

- 测试范围与不测项。
- 数据上限、奖品或库存消耗额度。
- 权限边界与允许的外部操作。
- 缺陷严重度、发布建议及风险接受。
- 无证据或仅有人工作证的结论。

无人工输入时，AI 可以继续只读分析和低风险验证，但不得假定写入、启停、删除、支付、领奖、发送消息或改权限已授权。
