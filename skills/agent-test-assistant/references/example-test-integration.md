# 示例：测试一体化项目

## 输入

- 模糊需求：测试 MeterSphere 的测试计划创建功能。
- 项目：测试项目-测试一体化。
- 项目性质：一次性。
- 项目关联用例：全部作为必须覆盖基线。

## 测试目标

验证用户能在正确项目和权限下创建测试计划，正确填写名称、时间、负责人、测试范围和关联用例；保存后列表、详情、统计和后续执行一致。覆盖校验失败、重复名称、边界时间、无权限、网络失败和重复提交。

## 需求追踪示例

| 需求 | 入口 | 核心验证 | 类型 |
|---|---|---|---|
| 创建测试计划 | 项目 → 测试计划 → 新建 | 表单、保存、列表和详情 | 基线 |
| 关联测试用例 | 新建计划中的测试范围 | 数量和内容一致 | 基线 |
| 必填校验 | 创建表单 | 缺失字段不能提交且提示清晰 | 基线 |
| 重复提交 | 保存动作 | 不产生重复计划 | 发散 |
| 时间边界 | 开始/结束时间 | 结束早于开始时被阻止 | 发散 |
| 权限 | 不同角色 | 无权限用户不可创建 | 发散/人工账号 |
